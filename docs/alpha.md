# α 粒子在铝箔中的能量损失

## 实验简介与目的

α 粒子穿过铝箔会损失能量，本实验用硅探测器与多道谱仪比较加箔前后的道谱，跟踪同一谱线的移动。

学习选择孤立峰、建立能量刻度并由峰移求能量损失，结合材料面密度与射程数据解释实际测量结果。

## 认识装置

在实验目录选择 α 能量损失实验，先查看“实验装置”。粒子路径依次为 **α 参考源 → 箔架 → 硅探测器**；硅探测器的幅度输出接到 **多道谱仪**。新实验从空源座、空箔架开始，源与薄箔分别装入。重开实验文件采用其保存的设置。

| 器材 | 作用与本课可观察量 |
|---|---|
| 源座与参考源 | 源座固定放射源的位置。装入三峰参考源后，可以观察三条 α 谱线。 |
| 箔架与薄箔 | 箔架把薄箔固定在源和探测器之间。先测空箔架，再加入铝箔，比较同一谱线的峰位。 |
| 硅探测器 | 将粒子沉积的能量转换为电脉冲，脉冲幅度用于区分能量。输出开关控制送给谱仪的信号。 |
| 多道谱仪 | 按脉冲幅度把计数分入各道，形成能谱；可采集、选峰和建立能量刻度。 |

本课提供 1 或 2 µm/片的铝箔（Al），可装 0–40 片。总厚度等于单片厚度乘片数；操作面板同时给出厚度和面密度。谱仪有 1024 道，道号为 0–1023。装置图是传播与接线示意，固定几何下不调探测距离；本课计算不包含空气路径损失。

装置动画只帮助辨认当前器材状态。散开的源束与空气中的少量背景点是视觉示意，不表示粒子轨迹、散射角、能量或输入脉冲，不参与计数。判断峰位和计数必须看多道谱仪；画面中的背景点也不表示本课模型加入了本底。

硅探测器输出与多道谱仪采集门分别控制，初始均关闭。探测输出关闭而仪器仍采集时，仪器继续累计曝光，关闭后的新增计数为零，已有累计计数保留；只开探测输出而仪器未开始时，实验室时间继续，仪器不累计曝光。空源也没有源峰，但与关探测输出是不同工况。本课程未模拟测量本底，因而空源长测也没有新增计数；这是本课近似，不能推广为真实仪器的本底恒零，也不能仅从零计数反推空源或断电。

## 原理与测量量

α 粒子穿过铝箔时损失能量；到达探测器的同一条谱线通常移到较低能量处。薄箔足够厚时，该谱线对应的粒子可能无法到达探测器，峰区没有计数，此时不能把消失的峰记为0 MeV。硅探测器产生的电脉冲按幅度分入谱仪各道，形成道谱；建立能量刻度后可换算为能谱。

直接测得的是各道整数计数和实际曝光。选一条孤立峰的ROI，以区内计数为权重求道重心；用参考能量建立刻度后，再换算峰能量并比较加箔前后的差值。相同曝光下，单道计数或峰区总计数描述强度，峰心位置描述能量，不能互相替代；曝光不同时先比较计数率。多条峰重叠或选区截断时，ROI重心未必代表其中某一条峰。

## 测量与刻度

1. 放入三峰参考源，将铝箔片数设为 0，启用探测输出并让多道谱仪采集参考谱。教学源选取 Pu-239、Am-241、Cm-244 各一条主线，能量依次为 5.155、5.486、5.805 MeV。在每个峰两侧选定只覆盖该峰的道区（ROI），用区内各道的计数作权重计算峰心。[α 能谱参考源表](https://www.ezag.com/products/isotope-products/isotrak-calibration-sources/reference-sources/alpha-spectroscopy-sources/)
2. 取两端峰的实测峰心 `c1`、`c2` 和相应的参考能量 `E1`、`E2` 建立线性刻度。用中间峰的峰心换算能量，再与 5.486 MeV 比较。保留参考谱和本次刻度。
3. 加入铝箔并重新采集，沿厚度递增的顺序跟踪同一条谱线。随峰移动调整 ROI，继续使用参考谱的刻度。记录厚度、曝光、选区、实测峰心和对应能量。如果峰区计数为零，记录零计数并将峰位留空。

```text
b = (E2 - E1) / (c2 - c1)               # MeV/channel
E(c) = E1 + b * (c - c1)
ΔE = b * (c_without_foil - c_with_foil) # MeV
```

刻度绑定实验、设备实例和道数。在同一仪器上更换铝箔时仍可使用这份刻度。道谱和刻度可分别保存，便于重新选区。[图形实验台](gui.md)

谱图始终显示全道0–1023，空谱、首次计数、换箔和叠加参考谱均保持相同横向范围。无箔时三条约 5–6 MeV 的谱线位于高道区。横轴标明道号或能量单位；显示范围不改变原始数据，导出仍含全部道及零计数道。当前谱、已保存谱和参考谱的选择、ROI 与刻度均在右栏“谱分析”。

在“谱分析”选谱并设置 ROI 起止道，按“计算 ROI 重心”，用区内计数计算 `Σ(道号 × 计数) / Σ计数`。结果保留本次所选谱、道界、截止曝光和刻度；继续采集、修改选区或刻度后，上次结果仍对应原输入，主动重算才更新。区内计数为零时重心不可求。只有 ROI 覆盖一条孤立峰时，才能把该重心解释为这条谱线的峰心。“计算”不等于“保存”：需保留测量时仍要主动保存原谱。重开实验文件后，选择已保存谱重新计算，不能把上次会话的结果当作自动留存。

## 一次课堂测量

1. 在源座选择三峰参考源，在箔架选择 1 µm/片、0 片。启用硅探测器输出，再打开“多道谱仪”，在“采集”页将方式设为定时、目标曝光设为60 s，然后开始测量。保存可读谱作为无箔参考；只下载整场而未在仪器上保存，不会额外保留这张谱。
2. 根据谱形分别在低能峰、高能峰选 ROI，按“计算 ROI 重心”并记录结果及对应截止曝光。这里的起止道都包含在选区内；不要把 ROI 中点直接当作峰心。
3. 将两峰的实测峰心与 5.155、5.805 MeV 填入两点能量刻度并应用。选中中间峰ROI，再按“计算 ROI 重心”，检查本次换算能量是否接近5.486 MeV。应用刻度不会自动更新上次冻结结果。把这条线作为后续能损测量的跟踪对象，保存本次刻度，再保存一份关联该刻度的无箔谱。保存刻度不改变已有道计数和截止曝光；兼容且尚未关联刻度的已保存谱会关联本次刻度，已有刻度关联保留。
4. 保存无箔谱后，清空当前读数，在装置页改为 1 µm/片、5 片（共 5 µm），再回谱仪开始新一轮，定时采集 60 s。选择无箔谱作参考，随中间峰移动调整 ROI。继续使用已有刻度，记录能量并与无箔中间峰比较。
5. 可依次测量 15 片与 30 片，跟踪中间峰并检查是否还有透射峰。每次先保存、清空当前读数，再更换工况并采集，记录规格、片数、总厚度与实际曝光。不同曝光下比较谱强度时按曝光归一；峰心比较仍使用原始道计数作权重。
6. 在各次仪器读数上主动“保存”，从“实验记录”导出所需道谱的 CSV/JSON 和能量刻度，或用“下载整场实验”带走 `.nuclemu` 文件。重新载入实验后，在“谱分析”选择已保存谱，用它的截止曝光填表。重开时仪器待机，查看旧谱不等于已把旧谱载入仪器；若要在其基础上续采，使用“载入测量数据”。零计数的峰区将峰心与能量留空，不能解释成测得 0 MeV 的峰。

加箔峰低于两条刻度参考线的能量范围时，换算依赖谱仪线性响应的假设。课堂采集不要求得到同一组随机计数。

## 数据处理与讨论

1. 给出两点刻度与第三峰检查结果，说明 ROI 的选择及其对峰心的影响。
2. 计算同一谱线能损并画出随面密度变化的曲线，保留测量和刻度身份。
3. 用 ASTAR 射程差估计面密度，说明单位、插值与几何值的差异。
4. 区分峰位、峰区计数与计数率，解释曝光不同、峰移出固定 ROI 和停止的影响。
5. 讨论计数统计及刻度误差。累计快照共享早期计数，不能当作独立重复测量。

## 用射程数据解释峰移

在 NIST ASTAR 中选择铝（Aluminum，材料号 013），用连续减速近似（CSDA）的质量射程 `R`，单位为 g/cm²。由无箔和加箔的实测峰能量估计穿过的面密度 `R(E_without_foil) − R(E_with_foil)`。两者采用相同单位时，可与几何面密度 `2.70 × 单片厚度(µm) × 片数 × 10⁻⁴ g/cm²` 对照，这里取铝密度为 2.70 g/cm³。面板若显示 mg/cm²，除以1000再填入表中的 g/cm²。[NIST ASTAR](https://physics.nist.gov/PhysRefData/Star/Text/ASTAR-t.html) · [NIST 列定义](https://physics.nist.gov/PhysRefData/Star/Text/programs.html) · [铝材料数据](https://physics.nist.gov/cgi-bin/Star/compos.pl?ap-text013)

本实验描述均匀纯铝箔中法向入射粒子的平均能损，采用固定几何和固定谱仪响应。模型忽略多重散射、能损涨落、空气和探测器死层损失、死时间及本底。接近停止厚度时，模型采用确定性的射程截止，因此实测趋势适于讨论峰移和停止，不能据此估计真实粒子的透射概率。
