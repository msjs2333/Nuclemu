# Web 实验工作台设计

**设计提案。** 本文规定学生从选择实验到保存退出的操作、仪器读数的归属，以及界面验收方法。第一种部署面向离线学生机。班级分发与教师控制另见[远景系列](vision/README.md)。

## 从目录到实验

主菜单按课程列出开放实验。每项包含一幅能辨认装置的插图、实验名、一句测量问题、所用仪器，以及“查看资料”“进入实验”。查看原理和步骤无需建立会话。进入实验后，浏览器标题采用“实验名 · Nuclemu”，页面把主要空间交给装置或数据。返回目录的入口统一为“退出实验”。

工作区采用三个应用内页签，共享同一个会话。第一次进入显示实验装置；从图中点击仪器可以直接定位到对应的仪器实例。公共栏保留采集门状态、仿真时间和倍速。全局暂停冻结实验室时钟；仪器上的停止按钮结清当前曝光，关闭采集门。

| 页签 | 主要内容 | 操作归属 |
|---|---|---|
| 实验装置 | 源、样品、探测器和读出仪器的相对位置与连接 | 点击或用键盘选择部件，查看用途、调整课程允许的参数；选中读出仪器可打开它的面板 |
| 测量仪器 | 所选设备的当前工况、实际曝光和读数 | 开始或停止采集、选择手动或定时、操作该仪器的分析工具 |
| 实验记录 | 同场各次采集、工况段、设备与刻度的对应关系 | 对照参考和样品，选择产品及格式导出；保存整场实验供下次查看 |

页签切换、缩放和查阅资料只切换视图。两个同型仪器以设备实例区分；在其中一台选的参考谱、刻度和 ROI 留在该仪器。切入测量仪器页后，若课程只有一台读出仪器，直接打开该仪器面板。

## 装置页与视觉层级

```text
实验装置    测量仪器    实验记录                    仿真时间    退出实验
─────────────────────────────────────────────────────────────────
  放射源       铝箔架       硅探测器                   多道谱仪
   [源座]  ⇢   [薄箔]   ⇢   [探头] ──── 电信号 ────► [读出]
               ↑ 已选
                                                铝箔架
                                                厚度 [ 5 ] µm
```

图中的相对位置解释实验几何；粒子路径和电信号线有各自的线型、方向和文字。课程模块声明哪些部件可调，以及哪个参数作用于模型。固定位置的探测器可点开看说明。α 的薄箔厚度按 µm 显示，β 的箔架按片数显示，并给出单片厚度。调整成功后，同一工况同时出现在仪器摘要和后续测量段。模型拒绝某个设置时，保留先前有效值，在部件旁显示原因。

插图采用统一视角的剖面或简化轴测，部件可辨认且有短标签。主要工作面用中性灰白，文字用石墨色，主操作与选中部件用同一强调色；参考谱用虚线，异常状态有文字。边框只用于界定输入区或独立工作面。窄屏先收合部件说明，保留图轴、单位和采集主动作。点选、键盘焦点和读屏名称应指向同一部件，悬停只作补充。教学示意如展示理想路径，应注明“示意”。装置图关联探测器数据的交互可参考 [Mantid Instrument Viewer](https://docs.mantidproject.org/v6.2.0/workbench/instrumentviewer.html)。

## 两种仪器的读数

**α 多道谱仪。** 主体显示道谱，横轴为道号或已刻度能量，纵轴标明每道计数。先采无箔参考谱，选两处隔离峰建立刻度，用第三个峰核对，再加箔追踪同一条谱线。拖选和键盘输入均可设定 ROI。选区内零计数时显示“无可测峰心”。刻度面板按需展开，图和两个参考点始终可见。切回道号轴保留刻度与原道谱。叠加两次不等曝光的谱时，图例给出各自曝光；若比较强度，可切换到明确标注单位的计数率轴。[InterSpec 谱分析界面](https://sandialabs.github.io/InterSpec/tutorials/intro_course_Sep2020/20200915_InterSpec_intro_part1.pdf)

**β 计数器。** 主视图为测量表，每行对应一段已知工况。列出本底或样品、箔片数、实际曝光、整数计数、计数率。选定本底记录后，适用的样品行显示净率及其标准不确定度。用样品与本底各自的曝光归一；本底自身显示为参考，负净率保留。普通重测直接开始新的一次采集，即使工况相同，也能在记录页分别选择。

## 保存与退出

学生导出可以多选产品，每项独立选格式，例如样品谱和本底谱分别用 CSV，两点刻度用 JSON。记录页的“保存实验”覆盖本次会话中可供学生重新查看的测量、工况、单位、仪器身份和刻度。单独导出一张谱后，其他记录和未保存的刻度保留未保存状态。整场保存需提供读回入口，读回后用已存数据恢复图和表。教师查阅的数据范围与精确续跑另见[档案和恢复](vision/03-records.md)。

| 触发 | 界面与会话行为 |
|---|---|
| 点击退出，已有未保存内容或正在采集 | 列明未存测量、刻度及活动曝光；显示“保存实验并退出”“放弃并退出”“继续实验”。确认期间冻结时钟 |
| 继续实验或取消文件选择 | 返回同一页签和所选设备，保持原门状态与剩余定时时长 |
| 写入失败 | 告知错误，保留原会话、采集门、定时终点及未保存内容。允许重试或继续实验。确认与写入期间不计入曝光 |
| 保存成功 | 保存当前物理时刻之前的有效曝光，成功后释放会话、返回目录。明确放弃时才丢弃未保存部分 |
| 已保存、未在采集 | 使用简短的退出确认，再返回目录 |
| 浏览器返回、刷新或意外关闭 | 应用内返回经过同一退出流程；按已完成的测量段更新本机恢复草稿，重新进入时显示最近恢复时刻。浏览器原生离开提示只作补充。[浏览器关闭事件](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event) |

## 前端与验收

首选验证 Vue 3、TypeScript 和 Vite 构建的静态界面，由学生机的本地 Python 服务提供页面与会话操作。资源随软件分发，课堂使用时可离线。实验定义提供目录、部件、参数和仪器实例；前端提交设置、开关门等操作，从会话读取已完成的测量。会话内核持有统一时钟与随机源，模型在给定物理区间内使用它们。切换后台和刷新不应改变相同物理操作时间线上的读数。浏览器后台节流要在课机上实测。[Vue](https://vuejs.org/guide/introduction.html) · [Vite 静态部署](https://vite.dev/guide/static-deploy.html) · [页面可见性](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)

验收用同一组课程操作从目录走到退出：

1. 查看 α 资料后进入装置页，从探测器找到多道谱仪，启动定时采集；切到装置页再返回，曝光仍按原终点结束。同种子、同操作时刻的道谱逐道与 CLI 对照。
2. 保留参考谱，加箔后重新采集；从记录页选出两次测量和适用刻度。保存、读回并切换横轴，原计数一致。
3. 进入 β 实验，分别测不等时长的本底和样品，核对工况、曝光、计数和净率。验证取消退出与保存失败均保留尚未保存的读数。
4. 在课机常用分辨率和系统缩放下，用键盘完成选部件、开门、选峰和退出。观察第一次接触界面的学生能否找到装置到读数的对应关系。

### 三个容易漏验的状态

- **保存失败后继续定时采集。** 设置 60 s 定时，在 14.5 s 选择“保存实验并退出”并模拟写入失败。选择继续后采集门仍开，剩余 45.5 s；最终读数和同种子、同工况、未经退出流程的对照一致。
- **读回时恢复分析依据。** 在两份不同曝光的 β 本底中选一份修正样品，保存并重新打开。核对引用的是同一条本底记录，样品净率和标准不确定度一致。对 α 记录核对参考谱身份、ROI 边界与实测峰心。
- **浏览器返回和刷新。** 在仪器页开定时门，按浏览器后退键触发退出确认。选择继续后，地址、页签、设备、采集门及剩余曝光仍对应原会话。另行刷新页面，核对最近已写入的草稿及其测量时刻；可恢复到哪一窗要在重新进入时显示。
