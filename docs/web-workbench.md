# Web 实验工作台设计

本文规定离线学生机的操作布局、各仪器的读数和界面验收方法。α 谱仪已确定工作台的视觉风格。β 实验、目录和实验记录采用同一套字体、部件插图和交互约定。

## 工作台推广计划

| 工作面 | 学生要做的事 | 布局与验收 |
|---|---|---|
| β 计数器 | 测本底，再测不同箔片数的样品，选取一次实测本底扣除 | 计数表为主工作面，本底选择紧邻表格。用两次不等曝光核对总计数、曝光、总率、净率和标准不确定度。切换本底引用后保留原始计数，包括合法零计数与负净率。 |
| 实验目录 | 比较测量问题和所用仪器，读资料、进入实验或读回档案 | 按课程组织，使用能辨认设备的插图。资料可独立打开；关闭资料或退出实验后，键盘焦点回到相应操作。 |
| 实验记录 | 找到哪台仪器在哪段工况下得到产品，选择导出内容与格式 | 将设备、测量段、工况和曝光分列。验证单项、多选及混合格式下载，检查同型设备和刻度产品能否区分。整场保存保留在文件菜单。 |
| 实验装置 | 识别源、样品、探头和读出仪器，理解连接，再调参 | 同一排实物脚底落在共同的台面线上，各图保持原比例，标签同行。粒子束穿过样品和探测窗，信号线接在电接口。桌面装置、目录缩略图和窄屏都核对脚底与端口。 |

中文正文和图轴使用思源黑体风格的无衬线字，正文、表头和单位使用黑色。用字号、字重、对齐与留白区分层级。颜色承担当前操作、采集状态、测量通道和错误提示。数字使用等宽数字并就近标注单位。每条解释放在学生要作决定的位置；页底省去重复的工况、曝光或连线说明，保留可访问的连接关系。空状态、保存失败和采集状态仍给出明确反馈。

离线字体 Nuclemu Lab Sans 取自思源黑体简体中文可变字体，保留当前界面所需字形。新增课程文字可回退到本机中文字体。[思源黑体源文件](https://github.com/adobe-fonts/source-han-sans) · [随包字体许可证](../nuclemu/static/lab-sans-LICENSE.txt)

实施先联调 β 本底与样品工作流，再从目录进入实验、从记录页导出并读回，最后用同一场数据做跨页面验收。桌面和 390 px 窄屏均检查可读性、键盘操作、页面溢出和视图切换。学生可见的计数、峰心及净率必须来自同一测量记录，教师专用的模型真值不进入学生仪器。

## 从目录到实验

主菜单按课程列出开放实验。每项包含一幅能辨认装置的插图、实验名、一句测量问题、所用仪器，以及“查看资料”“进入实验”。查看原理和步骤无需建立会话。进入实验后，浏览器标题采用“实验名 · Nuclemu”，页面把主要空间交给装置或数据。返回目录的入口统一为“退出实验”。

工作区顶栏放当前实验名和操作菜单，软件副标题仅用于启动目录等展示页。实验装置、测量仪器和实验记录共享同一个会话，宽屏从侧栏切换。第一次进入显示实验装置，从图中选择仪器可以直接定位到它的面板。仪器旁显示采集状态和实际曝光，仿真菜单提供倍率。探测与采集按设备启停，使用内核的统一时钟。

| 页签 | 主要内容 | 操作归属 |
|---|---|---|
| 实验装置 | 源、样品、探测器和读出仪器的相对位置与连接 | 点击或用键盘选择部件，查看用途、调整课程允许的参数；选中读出仪器可打开它的面板 |
| 测量仪器 | 所选设备的当前工况、实际曝光和读数 | 开始或停止采集、选择手动或定时、操作该仪器的分析工具 |
| 实验记录 | 同场各次采集、工况段、设备与刻度的对应关系 | 对照参考和样品，选择产品及格式导出 |

页签切换、缩放和查阅资料只切换视图。β 实验分析使用选定的本底记录计算净率，每台谱仪各自保存当前测量段、参考谱、刻度和 ROI。若另一页已切换仪器，旧页面提交选择时会提示重新查看仪器。课程只有一台读出仪器时，测量仪器页直接打开该面板。

## 装置页与视觉层级

仪器页将空间留给道谱或计数表，常用的开始、停止和当前曝光就近显示。定时、定计数、刻度和 ROI 工具放在仪器面板，文件操作在顶栏。β 在实验分析中选择实测本底。α 设置刻度时仍能看见谱峰。[Room EQ Wizard 的测量与图表布局](https://www.roomeqwizard.com/help/help/html/rewoverview.html)

图中的相对位置解释实验几何；粒子路径和电信号线有各自的线型、方向和文字。课程模块声明哪些部件可调，以及哪个参数作用于模型。固定位置的探测器可点开看说明。两课按片数调节，各自显示单片厚度和累计厚度。调整成功后，同一工况同时出现在仪器摘要和后续测量段。模型拒绝某个设置时，保留先前有效值，在部件旁显示原因。

α 主屏以浅灰和白色划分工具区和测量区。蓝色实线表示当前谱，暖色虚线表示参考谱，图例标明各自曝光。默认横轴取两条可见谱的有计数范围，显示菜单可以固定为全道。桌面展开分析时，右侧放选区与两点刻度，中央仍可操作谱图。学生读到的是当前仪器的道计数、实验工况和据此算出的峰心。源的参考能量在课程资料中给出。[Siemens iX 的工作面板](https://ix.siemens.io/docs/components/panes/guide)

装置示意使用按部件绑定的设备插图。粒子束与信号线分开绘制，随页面尺寸定位到设备。选择图中的设备或使用键盘均能打开对应的说明或仪表。插图上的屏幕留空，采集结果由仪器显示。[Mantid Instrument Viewer](https://docs.mantidproject.org/v6.2.0/workbench/instrumentviewer.html)

## 两种仪器的读数

**α 多道谱仪。** 主体显示道谱，横轴为道号或已刻度能量，纵轴标明每道计数。先采无箔参考谱，选两处隔离峰建立刻度，用第三个峰核对，再加箔追踪同一条谱线。拖选和键盘输入均可设定 ROI。选区内零计数时显示“无可测峰心”。刻度面板按需展开，图和两个参考点始终可见。切回道号轴保留刻度与原道谱。叠加两次不等曝光的谱时，图例给出各自曝光；若比较强度，可切换到明确标注单位的计数率轴。[InterSpec 谱分析界面](https://sandialabs.github.io/InterSpec/tutorials/intro_course_Sep2020/20200915_InterSpec_intro_part1.pdf)

**β 计数器。** 主视图为测量表，每行对应一段已知工况。列出本底或样品、箔片数、实际曝光、整数计数、计数率。选定本底记录后，适用的样品行显示净率及其标准不确定度。用样品与本底各自的曝光归一；本底自身显示为参考，负净率保留。暂停后继续累计。要做独立重测，可先缓存当前读数，清空仪器，再开始新测量。

## 保存与退出

仪器上的「保存」将当时的可读状态加入本场缓存。学生在记录页勾选并批量下载，或下载包含当前设置及全部缓存记录的整场实验包。清空当前仪器与退出会话分别处理，详见[采集、缓存与文件](measurement-workflow.md)。

| 触发 | 界面与会话行为 |
|---|---|
| 点击退出或替换当前实验 | 提示学生下载所需记录或整场文件，并提供返回实验和明确放弃的选择。若还有未缓存读数，学生可返回仪器保存 |
| 继续实验或取消文件选择 | 返回同一页签和所选设备，保持原门状态与剩余定时时长 |
| 写入失败 | 告知错误，保留原会话、采集门、定时终点及未保存内容。允许重试或继续实验。确认与写入期间不计入曝光 |
| 结束会话 | 学生完成所需下载或明确放弃后返回目录并释放临时缓存 |
| 已保存、未在采集 | 使用简短的退出确认，再返回目录 |
| 浏览器返回、刷新或意外关闭 | 应用内返回经过同一退出流程。服务仍在运行时，刷新直接接回当前实验。服务结束后从已下载的实验文件加载设置和记录。[浏览器关闭事件](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event) |

## 前端与验收

首选验证 Vue 3、TypeScript 和 Vite 构建的静态界面，由学生机的本地 Python 服务提供页面与会话操作。资源随软件分发，课堂使用时可离线。实验定义提供目录、部件、参数和仪器实例；前端提交设置、开关门等操作，从会话读取已完成的测量。会话内核持有统一时钟与随机源，模型在给定物理区间内使用它们。切换后台和刷新不应改变相同物理操作时间线上的读数。浏览器后台节流要在课机上实测。[Vue](https://vuejs.org/guide/introduction.html) · [Vite 静态部署](https://vite.dev/guide/static-deploy.html) · [页面可见性](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)

验收用同一组课程操作从目录走到退出：

1. 查看 α 资料后进入装置页，选中多道谱仪并打开其面板，启动定时采集；切到装置页再返回，曝光仍按原终点结束。同种子、同操作时刻的道谱逐道与 CLI 对照。
2. 保留参考谱，加箔后重新采集；从记录页选出两次测量和适用刻度。保存、读回并切换横轴，原计数一致。
3. 进入 β 实验，分别测不等时长的本底和样品，核对工况、曝光、计数和净率。验证取消退出与保存失败均保留尚未保存的读数。
4. 在课机常用分辨率和系统缩放下，用键盘完成选部件、开门、选峰和退出。观察第一次接触界面的学生能否找到装置到读数的对应关系。

### 三个容易漏验的状态

- **保存失败后继续定时采集。** 设置 60 s 定时，在 14.5 s 发起退出并模拟整场文件导出失败。选择继续后采集门仍开，剩余 45.5 s；最终读数和同种子、同工况、未经退出流程的对照一致。
- **读回时恢复分析依据。** 在两份不同曝光的 β 本底中选一份修正样品，保存并重新打开。核对引用的是同一条本底记录，样品净率和标准不确定度一致。对 α 记录核对参考谱身份、ROI 边界与实测峰心。
- **多页操作与恢复。** 两个页面连接同一场定时采集。一个页面取消退出并继续采集后，另一页此前打开的退出确认即告失效，新增曝光和缓存均保留。刷新仍在运行的会话可返回该场实验；另行重启服务后，从文件打开此前下载的设置和全部缓存记录。
