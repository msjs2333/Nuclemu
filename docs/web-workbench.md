# Web 实验工作台设计

本文规定离线学生机的操作布局、各仪器的读数和界面验收方法。α 谱仪已确定工作台的视觉风格。β 实验、目录和实验记录采用同一套字体、部件插图和交互约定。

## 桌面布局与测量

页面与组件的交付标准见[工作台交付与验收](workbench-acceptance.md)。目录、装置、α 谱图、β 双窗、实验记录和内置教材共用实验导航与字体。顶栏显示实验名，左栏选页面，仪器操作集中在常驻右栏。退出或替换实验保留离场确认。

α 的工作面优先显示谱图，右侧“采集／谱分析”分别管理开门、目标、ROI 和刻度；两点能量刻度在“谱分析”内展开。当前与参考谱以线型和颜色区分，配上各自的工况与曝光。β 的一台计数器左右并列显示 A、B 两窗，各列大数下设置单次曝光，整机共同开始、继续与暂停；保存、清空与载入另选目标窗。仪器展示原始逐窗读数，学生导出后处理本底。装置的操作面板可直接调参，单击设备可了解原理和本课作用。整机接线从右上打开。

视觉参考包括 [Siemens iX 工作面板](https://ix.siemens.io/docs/components/panes/guide)、[Mantid 的仪器查看器](https://docs.mantidproject.org/v6.2.0/workbench/instrumentviewer.html)与 [InterSpec 谱分析界面](https://sandialabs.github.io/InterSpec/tutorials/intro_course_Sep2020/20200915_InterSpec_intro_part1.pdf)。实际测量时的选峰、刻度、暂停及读数位置见上面的操作验收表。

离线字体 Nuclemu Lab Sans 取自思源黑体简体中文可变字体，保留当前界面所需字形。新增课程文字可回退到本机中文字体。[思源黑体源文件](https://github.com/adobe-fonts/source-han-sans) · [随包字体许可证](../nuclemu/static/lab-sans-LICENSE.txt)

## 保存与退出

仪器上的「保存」将当时的可读状态加入本场缓存。学生在记录页勾选并批量下载，或下载包含最终设置、全部轮次与工况变更，以及学生已保存的测量快照的整场实验包。清空当前仪器与退出会话分别处理，详见[采集、缓存与文件](measurement-workflow.md)。

| 触发 | 界面与会话行为 |
|---|---|
| 点击退出或替换当前实验 | 提示学生下载所需记录或整场文件，并提供返回实验和明确放弃的选择。若还有未缓存读数，学生可返回仪器保存 |
| 继续实验或取消文件选择 | 返回同一页签和所选设备，保持原门状态与剩余定时时长 |
| 写入失败 | 告知错误，保留原会话、采集门、定时终点及未保存内容。允许重试或继续实验。确认与写入期间不计入曝光 |
| 结束会话 | 学生完成所需下载或明确放弃后返回目录并释放临时缓存 |
| 已保存、未在采集 | 使用简短的退出确认，再返回目录 |
| 浏览器返回、刷新或意外关闭 | 应用内返回经过同一退出流程。服务仍在运行时，刷新直接接回当前实验。服务结束后从已下载的实验文件加载设置和记录。[浏览器关闭事件](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event) |

## 前端与验收

首选验证 Vue 3、TypeScript 和 Vite 构建的静态界面，由学生机的本地 Python 服务提供页面与会话操作。资源随软件分发，课堂使用时可离线。实验定义提供目录、部件、参数和仪器实例；前端提交设置、开关门等操作，从会话读取已完成的测量。会话内核持有统一时钟与随机源，模型在给定物理区间内使用它们。切换后台和刷新不应改变相同物理操作时间线上的读数。浏览器后台节流要在课机上实测。[Vue](https://vuejs.org/guide/introduction.html) · [Vite 静态部署](https://vite.dev/guide/static-deploy.html) · [页面可见性](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)

验收用同一组课程操作从目录走到退出：

1. 查看 α 资料后进入装置页，选中多道谱仪并打开其面板，启动定时采集；切到装置页再返回，曝光仍按原终点结束。同种子、同操作时刻的道谱逐道与 CLI 对照。
2. 保留参考谱，加箔后重新采集；从记录页选出两次测量和适用刻度。保存、读回并切换横轴，原计数一致。
3. 进入 β 实验，分别测不等时长的本底和样品，从文件核对每窗工况、曝光和整数计数，在外部复算净率。验证取消退出与保存失败均保留尚未保存的读数。
4. 在课机常用分辨率和系统缩放下，用键盘完成选部件、开门、选峰和退出。观察第一次接触界面的学生能否找到装置到读数的对应关系。

### 三个容易漏验的状态

- **保存失败后继续定时采集。** 设置 60 s 定时，在 14.5 s 发起退出并模拟整场文件导出失败。选择继续后采集门仍开，剩余 45.5 s；最终读数和同种子、同工况、未经退出流程的对照一致。
- **读回时恢复分析依据。** 在 CLI 显式指定一份 β 本底修正样品，保存整场并重新打开。核对引用的是同一条本底记录，样品净率和标准不确定度一致。对 α 记录核对参考谱身份、ROI 边界与实测峰心。
- **多页操作与恢复。** 两个页面连接同一场定时采集。一个页面取消退出并继续采集后，另一页此前打开的退出确认即告失效，新增曝光和缓存均保留。刷新仍在运行的会话可返回该场实验；另行重启服务后，从文件恢复最终设置、各轮工况历史和全部缓存记录。
