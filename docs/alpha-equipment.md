# α 器材、接口与联调读数

本页供课程作者、GUI 和 CLI 维护者核对器材与数据。学生步骤见[α 能损](alpha.md)，公开射程依据及模型近似见[模型参考](model-reference.md#alpha)。以下 Python 入口已实现；新的图形操作与缓存文件入口仍按[测量流程](measurement-workflow.md)联调，不把未保存的当前道谱当作已保存快照。

## 器材与端口

| 部件 ID | 可调项或绑定 | 约定 |
| --- | --- | --- |
| `source` | `source_present`：0 空源座（新实验默认），1 三峰参考源 | 选取 5.155、5.486、5.805 MeV 三条主线。模型无本底，空源输出零计数；不是探测器电源开关。已有文件按保存的源座末态恢复。 |
| `foil` | `foil_spec_um`：1 或 2 µm/片，默认 1；`foil_count`：整数 0–40，默认 0 | 同规格均匀纯 Al 薄片，0 片为空架。规格是课程教学设定，不代表材料实测证书。 |
| `detector` | `Component.output="alpha_detector"` | 硅探测器的独立输出开关。没有绑定 `device`，不会被当成 MCA 面板入口。 |
| `mca` | `Component.device="mca"`、`Device.input="alpha_detector"` | 1024 道，独立采集门；Nuclemu 文件以实验 ID `alpha`、设备 ID `mca` 标识该谱仪。 |

粒子路径为 `source → foil → detector`，信号电缆为 `detector → mca`。`SignalOutput` 的道数为 1024，单位 `count`，时基 `s`，返回区间内各道整数计数。已包含固定几何、每线平均 25 s⁻¹ 的有效探测率、12 keV 标准差高斯响应及 0.006 MeV/道量化；读出端不再乘效率或重复展宽。同一输出可无损分接到第二台 MCA，两台同期逐道计数应相等。

总厚度 `t_um = foil_spec_um × foil_count`；传给共享 `AluminumFoil` 的厚度为 `t_um / 1000 mm`，面密度为 `2.70e-4 × t_um g/cm²`。

| 规格 / µm | 片数 | 总厚度 / µm | 面密度 / g/cm² |
| ---: | ---: | ---: | ---: |
| 1 | 0 | 0 | 0 |
| 1 | 1 | 1 | 0.000270 |
| 1 | 5 | 5 | 0.001350 |
| 2 | 3 | 6 | 0.001620 |
| 2 | 40 | 80 | 0.021600 |

较厚堆叠只会落入完全停止状态，不对 ASTAR 能量表外推。固定几何、法向入射、忽略空气与死层损失的假设未变；没有开放源距或另乘几何效率。空源、空箔、关探测输出、关仪器门必须分别显示：前两项属于装置工况，后两项独立控制时间需求与曝光。固定器材名称为“箔架”；空时为“空箔架”，装样后可写“铝箔（Al）· 2 片”，材料名跟随样品。

## 可运行入口

从仓库根目录运行：

```text
python -m examples.alpha_equipment
python -m unittest discover -s tests -p test_alpha.py -v
python -m nuclemu run alpha --device mca --enable-output alpha_detector --duration 60 --set source_present=1 --set foil_spec_um=1 --set foil_count=5 --roi 764:794
```

最小公共调用为：

```python
from nuclemu.catalog import discover
from nuclemu.core import Session
from nuclemu.results import MeasurementView

s = Session(discover()["alpha"], seed=187)
s.configure({"source_present": 1, "foil_spec_um": 1, "foil_count": 5})
s.set_output("alpha_detector", True)
s.start(60, device="mca")
s.advance(60)
product = MeasurementView(s).product()
assert s.instrument("mca").exposure_s == 60
s.set_output("alpha_detector", False)
```

初始输出与门均关闭；`start` 不开启探测输出。示例最后关闭探测输出后，若所有仪器门也关闭，实验室待机。只开探测器时允许时间推进，MCA 不累计曝光；只开 MCA 门时保留实际曝光和合法零计数。关输出不等于移走源。

[`examples/courses/alpha_fine_foil.py`](../examples/courses/alpha_fine_foil.py)通过 `dataclasses.replace` 复用整套器材、端口和模型，只在这门扩展课增加 0.5 µm/片。运行 `python -m nuclemu gui --path examples/courses` 可发现它。扩展课的 0.5 µm × 6 片与基础课 1 µm × 3 片给出同一物理厚度；没有在前端另写能损公式。同型第二台谱仪只须声明新的 `Device.id` 和组件绑定，并接入同一输出，门与曝光各自独立。

## 物理参考接口与装置画面

`EXPERIMENT.particle_flow(settings)` 保留为纯物理参考接口，`Session.particle_flow` 按有效设置缓存其 JSON 数据；它不调用采集抽样或随机数。返回材料、总厚度、面密度、入射/透射有效率，以及各条线的 `incident_MeV`、`residual_MeV`、`incident_rate_s`、`transmitted_rate_s`。能量直接复用 `transmitted_energy` 的 CSDA 插值，与采谱采用同一材料和停止条件。这些字段供技术核验和课程扩展使用，不作为画面中点的数量、颜色、速度或方向的标尺。

接口中的每线 25 s⁻¹ 与总 75 s⁻¹ 是已包含固定几何和探测效率的有效率，不能解释为源的总活度或整个空间的粒子通量。源座为空时接口中的源信号率为零；装源后关闭电输出不会移走放射源，只会阻断送入谱仪的信号。实际整数计数由采集模型产生，能量由原始道谱与适用刻度确定。

| 1 µm 单片的片数 | 入射有效率 / s⁻¹ | 透射有效率 / s⁻¹ | 三条线穿箔后的能量 / MeV |
|---:|---:|---:|---|
| 0 | 75 | 75 | 5.155、5.486、5.805 |
| 5 | 75 | 75 | 4.306740591、4.673631579、5.032983587 |
| 25 | 75 | 25 | 前两条停止；第三条 0.422960993 |
| 30 | 75 | 0 | 三条均停止 |

装置图中的视觉扇束和背景点仅作器材状态示意，与计数、能量或角分布没有换算关系。不能按点数、疏密、颜色、运动速度或扇形开角求计数率、能损、散射角或透射概率，也不能用图中点的出现或消失判定模型的射程截止。背景点不代表本课加入了环境本底；α 采集模型仍无本底。扇束外观不表示计算中加入了角分布、单粒子轨迹或箔内停止坐标。

画面验收核对源座、箔片、探测输出等操作状态是否清楚且互相独立，不以图中点与上表数值相等为判据。计数、曝光、能量及停止边界应通过仪器读数和已保存谱的 CSV/JSON 核验。动画开关、帧率与读取参考接口均不得调用采集随机流；同一设置和操作时间线下，道谱、曝光及缓存保持一致。

## 实际 ROI 与峰心

### Web 手动分析快照

谱仪的 `state.readout` 只提供当前所选谱的实时总计数、实际曝光和计数率，不在轮询中计算 ROI。选区拖动或 `analysis` 的 `roi` 字段只改变选区。按“计算 ROI 重心”时，客户端提交 `calculate_roi`、`device`、含两端的 `roi=[first,last]` 与最近状态中的 `roi_context`。上下文绑定仪器、已存记录 ID／分段索引和采集轮次；目标已经改变时拒绝旧操作。

`state.roi_result` 初始为 `null`，成功计算后包含当次完整道谱 `counts`、道界 `roi`、截止曝光 `exposure_s`、所选谱上下文、适用刻度文档 `calibration`，以及 `readout` 内的区内计数、计数加权重心和换算能量。未标定仍可给道重心；空区给零计数、重心和能量为 `null`，不拟造峰。计算不暂停采集，不消耗采集随机流，也不自动保存测量。

继续采集、换箔、改选区、更新刻度或切到另一份谱，均不改写该设备上次的 `roi_result`。再次点击才以届时选中的谱和刻度生成新结果，界面须同时标明该结果的道界和截止曝光，不能把它与新的实时计数混用。该结果是会话内分析快照；页面刷新仍可读取，重新打开整场文件从未计算开始。需要携带原谱时，仍由学生显式保存道谱；文件重开后可以主动重算。

### 空源的适用边界

本课目标是孤立 α 谱线的刻度和能损，当前模型保留“忽略本底”的明确近似。空源即使长时间开门仍为零，这只描述本课模拟，不能推广成真实硅探测器长测恒零。[ORTEC ULTRA/ULTRA-AS 资料](https://www.ortec-online.com/products/radiation-detectors/silicon-charged-particle-radiation-detectors/si-charged-particle-radiation-detectors-for-alpha-spectroscopy/ultra)给出的特定 450 mm² 探测器系统在 3–8 MeV 区间的保证本底不超过 24 次/日，并说明探测器与腔室洁净度会影响低本底表现。这是指定面积、能区和系统条件下的规格，不能直接挪成本课全道谱的随机本底。

本轮不从 β 本底率、画面背景点或任意均匀道分布补出 α 本底。若课程以后要求空白谱、检出限或低能尾部分析，应先确定探测面积、能区、腔室和阈值等条件及可核验谱形，再独立建立背景响应。空源、关闭探测输出和关闭采集门仍是三个不同操作：是否有源信号、是否送出信号、是否累计曝光分别由相应设置决定。

### 连续工况复算例

`examples.alpha_equipment` 采用种子 187：启用输出，在同一 **240 s** 的 MCA 门内，于 0、60、120、180 s 分别应用 1 µm/片的 0、5、15、30 片。每个工况段恰为 60 s，期间不增加其他操作；最后关闭探测输出。该连续时间线用于接口复验，不代替仪器主动保存与分轮测量的课堂操作。

无箔两端 ROI 为 845–874、952–982 道，实测峰心分别为 **859.193818416**、**967.472184532** 道，对应 5.155、5.805 MeV。中间峰不参与刻度。

| 片数（规格 1 µm） | 全谱计数 | 中峰 ROI / 道（含两端） | ROI 计数 | 峰心 / 道 | 换算能量 / MeV |
| ---: | ---: | --- | ---: | ---: | ---: |
| 0 | 4536 | 900–929 | 1509 | 914.266401590 | 5.485603244 |
| 5 | 4569 | 764–794 | 1558 | 778.927471117 | 4.673157434 |
| 15 | 4449 | 434–464 | 1500 | 448.978666667 | 2.692459622 |
| 30 | 0 | 全谱 0–1023 | 0 | 无 | 无 |

5 µm 的实测峰移约 **0.812445809 MeV**。这些是统计模型的实际读数，不是独立实验数据或每次测量的标准答案。15 µm 结果低于参考线范围，依赖线性电子学响应假设。程序另输出所有三峰的 ROI、区内计数、峰心和能量，可与仪器上主动保存并导出的 CSV/JSON 原始道谱复算核对；零计数不报告峰心。

## 刻度归属与跨工况复验

运行 [`examples.alpha_review_cases`](../examples/alpha_review_cases.py) 并显式指定生成目录：

```text
python -m examples.alpha_review_cases OUTPUT_DIRECTORY
```

样例写出实际采集的整场文件、单份 JSON 道谱及独立刻度文件。`history-3mev` 与 `current-6mev` 都来自种子 187、有源无箔的 3 s 谱，共 221 次；ROI 900–929 内为 59 次，峰心 914.389830508 道。两份文件仅刻度不同：1000 道分别为 3、6 MeV，中峰换算为 2.743169492、5.486338983 MeV。前一刻度仅用于故意改变刻度的操作核验，不是这台谱仪的物理真值。

`mixed-2s-plus-1s` 在同一轮前 2 s 无箔、后 1 s 加入 1 µm 箔，保存一次累计谱：整张为 221 次、3 s，两段分别为 153 次/2 s 与 68 次/1 s，保留各自设置。不得把整谱标为单一箔厚；整谱各道应等于两段逐道相加。两段的中峰位置不同，整谱重心也不是任何单独工况的谱线能量。

按以下操作核对公共谱仪和文件层：

1. 本场应用 6 MeV 刻度，查看 3 MeV 刻度的历史谱，再直接开始采集；另走先手动切回本轮后开始。两条路径都恢复本场 6 MeV 刻度。回到历史谱仍使用其 3 MeV 刻度，原始道数、曝光、峰心道址均不改变。
2. 已保存有效刻度时，对同一份暂停的 2 s 谱先普通保存，再清空选保存。导出的两条测量逐道计数、曝光及 `calibration_id` 相同，重开后同 ROI 的峰能量一致。
   保存刻度先打开命名窗口，预填实验缩写、时间和刻度标识；接受默认名或修改后确认才加入本场记录。取消不新增刻度；失败保留名称供重试。记录页可再次改名，刻度 ID 和已关联道谱保持不变；单项 JSON、整场文件及重开仍应保留名称和刻度数据。
3. 跨工况整包重开时先待机，可选整份 221 次/3 s 的已存谱，也能核对两段工况；历史查看不得重新抽样。
4. 重开后新轮使用文件层记录的独立随机流来源，并可由同档和同操作复验；保留旧谱不变。`random_stream` 保存 `scheme`、根 `seed` 和 `generation`，本轮 `RoundInfo.random_stream` 记录来源。当前方案 `python-random-sha256-v1` 在初建 generation 0 使用原种子；重开 generation 加一，按 `python-random-sha256-v1:{seed}:{generation}` 的 ASCII 字符串计算 SHA-256，将摘要按大端整数初始化新流。检查来源及同档复现，不能以两份随机计数恰好不同代替检查。

## 旧厚度与刻度兼容

新课程只公开规格与片数，厚度为派生量。`Experiment.normalize_settings` 仅在共用 `Session.configure` 设置边界兼容旧命令：

- 旧实时 `foil_um=0` 或 `foil_um=5` 分别明确转成 1 µm 规格的 0 片或 5 片，允许整数 0–40 µm。`Session.set`、CLI 和工作台沿用同一入口。
- 2.5 µm 等不可按默认 1 µm 片精确表示的旧实时输入给出迁移提示，整个设置批次不生效。同批混用 `foil_um` 与任一新箔键时报歧义，即使数值看似一致也不选一方覆盖。
- 旧档读取独立于该转换。档案里的 `foil_um=2.5` 始终是原始总厚度；读回与另存均保持 2.5 µm 和原道谱，片数、规格未知，不补整数片数。
- 实验 ID `alpha`、设备 ID `mca`、1024 道和固定电子学映射不变，旧 `nuclemu.calibration/1` 刻度仍适用。源或箔变化不属于电子学刻度工况；对无峰的谱不据刻度生成不存在的读数。

专项测试覆盖空源/空箔四种组合、规格与单位、等厚堆叠、探测与读出门、共享输出、峰移与停止、显示回调不改变测量、扩展课规格、批量兼容的原子失败、2.5 µm 旧档读回另存及旧刻度。课程专项不能替代公共文件层的导出/重开和桌面操作验收；同机独立服务的走读也不能等同于物理第二台电脑的验收。
