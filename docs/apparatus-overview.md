# 装置与接线

两门实验的整机工作过程如下。测量步骤与记录表分别见[α 学生实验](alpha.md)和[β 学生实验](beta.md)。

## α 能量损失

源座固定 α 参考源，箔架位于源和硅探测器之间。空箔架用于取得参考谱；加箔通常使同一条可见谱线的峰位降低，足够厚时该谱线对应的 α 粒子可被阻止，谱峰消失。硅探测器把粒子沉积的能量转换成电脉冲，经电缆送到多道谱仪；谱仪按脉冲幅度分道累计，形成能谱。比较同一条谱线加箔前后的峰位，可研究能量损失。

本课采用固定的源、箔架和探测器位置，不调探测距离，不另计算空气路径损失。探测输出开关控制送出的电信号，多道谱仪的开始、继续与暂停控制采集；关闭输出不清除已有计数，门仍开时曝光继续累计、新增 α 计数为零。动画仅提示当前器材状态，不能从画面点数或轨迹读取能量和计数。

## β 吸收

源座固定 β 源，箔架位于源和探测器之间。粒子穿过铝箔后，能被探测到的计数随材料厚度而变化。探测器将探测到的粒子转换为计数脉冲，经信号电缆送到一台计数器。本虚拟课程将左侧 A 窗和右侧 B 窗作为同工况的两组重复观测，按同一平均响应分别取样、按各自单次曝光留读；这不表示把同一真实脉冲抽样两次。探测输出共用一个开关，整机共同开始、继续与暂停。比较相同探测条件下不同箔厚的计数率，可研究吸收趋势。

本课采用固定几何，不调探测距离，不另计算空气路径损失。取下源、保持探测输出开启，再开始测量，可取得环境本底；关闭探测输出不能代替本底测量。保存、清空或载入测量数据只作用于所选窗。动画仅提示当前器材状态，空气中的背景点不代表实际本底计数。
