# Nuclemu 文档

**A Virtual Nuclear Physics Lab**

按阅读目的选择一本书。学生版与工作台“实验资料”共用 α、β 两章正文；目录预览读取各章第一节“实验简介与目的”。教师示例与模型参数不进入学生默认资料。

| 书册 | 阅读路径 |
|---|---|
| [学生实验手册](student.md) | 认识装置、测量、保存原始读数，填写空表并自行处理数据。 |
| [教师教学用书](teacher/README.md) | 组织两门实验，设计测点，讨论统计与常见错误。 |
| [实验技术参考](technical/README.md) | 核对模型、单位、设备、采集与文件接口及复验依据。 |

工作台启动与文件操作见[图形实验台](gui.md)，命令行入口见[CLI](cli.md)。
