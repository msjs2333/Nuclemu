# 实验框架与工作台设计

一次运行由实验定义创建独立会话。图形工作台与命令行向会话提交相同的装置操作并读取相同的结果。以 β 吸收为例，换一片箔会改变装置工况，模型据此给出下一段曝光的期望计数，计数器产生读数；界面、表格和导出器共享这次读数。

## 模块与状态

| 部件 | 职责与接口边界 |
|---|---|
| 物理基础库 | 定义时刻、时长、长度、能量、活度、计数率等量及其单位。常量、材料和响应表记录来源、版本与适用区间。材料定义可共享，每片箔的厚度和位置由实验实例持有。 |
| 实验定义与目录 | 独立模块声明标识、名称、装置组成、模型、参数范围、允许操作及输出。目录发现模块并检查依赖，GUI 和 CLI 共用同一份目录。 |
| 模型与仪器 | 模型读取装置工况、模拟区间和受控随机源。端口声明传递的量、单位、通道、时基，以及已计入的效率或展宽。仪器从可观测信号取得计数、道谱或时间差等结果。 |
| 会话与采集 | 会话持有时钟、装置实例、模型状态和随机源。采集器控制通道、采集窗与停止条件；本底和样品可以分别测量，并各自保存曝光。 |
| 工作台与文件输出 | 工作台根据设备类型选择面板，再绑定到当前会话的设备实例。写入器按产品和格式读取已经取得的结果。 |

## 时间与数值模型

**信号分接。** 将一个理想探测器的输出无损分接到两台计数器，使用完全相同的采集窗，且两路均无独立丢失。两台计数器读取同一批脉冲，每个窗的计数应逐次相等。验收时逐窗比较两列整数；分别按同一平均率抽样只能复现各路的统计分布。

每场实验有一个实验室坐标时刻 `t_lab`，由会话内核推进。变速改变墙钟等待时间；模型可在同一物理区间内按窗积分、按道抽样或处理有时间关联的事件。世界暂停时状态冻结，关采集门只停止记录，已活化样品仍会衰变。

### 图形和命令行的公共调用

两个入口由 `discover(paths)` 取得实验定义，再创建 `Session(experiment, seed)`。命令行可以一次推进整段曝光，图形端可以分多次推进。设置值、开始与停止操作都落在实验室时钟上。例如，下列调用连续测量两次相同工况，得到两份可分别选择的谱：

```python
from nuclemu.catalog import discover
from nuclemu.core import Session
from nuclemu.results import MeasurementView

session = Session(discover()["alpha"], seed=187)
view = MeasurementView(session)
for seconds in (2.25, 1.25):
    session.start(duration_s=seconds)
    session.advance(seconds)
first, second = view.product()["segments"]
assert (first["acquisition"], second["acquisition"]) == (1, 2)
```

每次开门分配一个会话内的采集序号。一次采集中改变工况会产生同一序号下的新段。每个段保留起止时刻、工况、设备实例 ID 和整数读数；曝光是该段起止时刻之差。程序可用 `collect` 批量整理记录；持续更新的面板用 `MeasurementView.product()` 读取同样的结构。这个视图仅合并新封闭的测量窗，调用方按只读方式使用。选择仪器、改变横轴和导出都使用已有读数。谱的 `roi_centroid` 按所选道区（含两端）计算计数加权峰心，零计数区没有可报告的峰心。

若在模拟时刻 30 s 换片，先按原厚度结算此前的曝光，再让新厚度生效。跨工况的测量需注明变化或分段输出。同一探测器连续两个 5 s 窗获得 7 和 9 次计数，则覆盖这两个窗的总数为 16。增加一次图形刷新不消耗模型的随机数。固定模型版本、数值环境、种子与操作时刻后，GUI 与 CLI 应能复现同一科学读数。

**定数停采。** 目标为 100 次、本次采集已接受 98 次时，若下一批有 7 个合格计数，采集器应在本批第 2 个合格计数处关门，总计 100 次，曝光结算到该计数的模拟时刻。固定模型、种子和操作时刻，改变 CLI 批大小后，总数、停止时刻与曝光应相同。

## 接入一个实验

1. **装配。** 作者在实验模块里实例化源、样品和探测器，选择可复用模型或实现新模型。空间布置描述照射路径，信号连接描述仪器读到什么。
2. **声明。** 列出可调量、单位、有效范围、默认值和输出。模型注明覆盖的物理过程与已包含的响应。固定距离标定的经验计数模型不能支撑开放调距的实验，装配校验应指出冲突。
3. **运行。** 框架从定义创建会话，应用参数操作，推进物理时间，开始或停止采集。专用仪器可自行处理符合窗、驱动相位等内部状态，通过公开接口提供读数。
4. **验证。** 作者提供一组输入工况及期望的物理响应。将模块加入本地目录以后，两个入口都应能发现和运行它，无需改动内核或主菜单。作者文档需包括一个计数示例、一个关联谱示例及对应的错误诊断。

当前本地目录按单个 Python 文件加载实验定义。可从已安装的 Python 包导入共用模型，并以模块的 `__file__` 定位旁边的参考数据。目录本身不会加入 Python 的模块搜索路径；多文件课程库可安装为包，再由目录中的实验定义导入。

Web 目录读取 `Experiment` 的 `question` 和 `guide` 展示测量问题与步骤。各部件通过 `Component.parameters` 绑定同名模型参数，通过 `Component.device` 绑定读出仪器的实例 ID。同一探测器和仪器面板可以指向同一个读出实例。按装置顺序声明部件，用 `Connection` 明确照射路径（`particle`）和信号连线（`signal`）。已声明的装置图需能定位每个参数和设备。省略装置图的模块自动生成参数区和各设备入口。

例如，将下列内容保存为可信课程目录中的 `counter_lab.py`，使用 `python -m nuclemu gui --path 课程目录` 进入工作台，也可用 `python -m nuclemu run clock-pulses --path 课程目录 --duration 3` 检查读数。

```python
from math import floor
from nuclemu.core import Component, Connection, Device, Experiment, Parameter

def count_pulses(settings, start, end, rng):
    # 周期信号在整数秒发出一个脉冲，分窗计数之和等于整段计数。
    pulses = floor(end) - floor(start)
    return {"scaler": (pulses * settings["enabled"],)}

EXPERIMENT = Experiment(
    "clock-pulses", "周期脉冲计数", "改变采集时长并检查累计读数。",
    (Parameter("enabled", "发生器开关", "", 1, 0, 1, integer=True),),
    (Device("scaler", "counter", "脉冲计数器"),), count_pulses,
    question="每秒一个脉冲，3 秒内会记录多少个？",
    guide=("启用发生器，定时采集 3 秒，读取计数器。",),
    components=(
        Component("generator", "source", "脉冲发生器", parameters=("enabled",)),
        Component("readout", "instrument", "数字计数器", device="scaler"),
    ),
    connections=(Connection("generator", "readout", "signal", "逻辑脉冲"),),
)
```

模型返回的键仍是设备 ID。目录加载时会报告未声明的参数、设备或连线端点，并给出模块位置。编辑装置显示文字和浏览资料都不创建会话或推进时钟。

### 具名选项、本底识别与课程分组

数值参数可追加 `options=((0, "本底"), (1, "有源"))`。非空选项是完整的允许值集合，必须含默认值；选项值仍满足参数范围与整数约束，且数值不重复。界面显示标签，模型、CLI 和测量工况仍使用数值。例如 β 的 `source_present` 显示“本底 / 有源”；其他实验可使用自己的键和值。未声明选项时保留原数值输入行为。

计数器可声明 `Device("counter", "counter", "计数器", background_conditions={"source_present": 0})`。声明会在定义加载时归一为不可变键值对，并检查引用的参数和值。条件按“且”匹配记录中的工况，不依赖实验 ID、参数名称或标签。非空声明用于识别可选本底；空声明表示没有自动识别规则，允许使用者显式选择适用的参考段，界面不能凭某个键或零值推断本底。具名选项只负责输入和显示，本底身份只由设备声明负责，两者独立。

本底和样品须对应同一读出设备、互不重叠的有效曝光；同一段不能当作自己的独立本底。同一次开门中切换工况形成的不同曝光段也可以独立，不要求不同的 `acquisition`。本底行保留原读数并标为参考，其他适用样品以各自实际曝光计算净率及独立泊松标准不确定度，允许负净率。条件匹配只识别工况，不能证明所有几何和模型条件都适用；模块作者仍需说明。CLI 的显式 `--background` 选择行为保持兼容。

`Experiment.course` 是可选的非空课程名称，默认 `"核物理实验"`，目录按该文字分组；无需额外课程注册或插件体系。`describe()` 输出的相关字段例如：

```json
{
  "course": "核物理实验",
  "parameters": [{"key": "source_present", "label": "测量模式", "unit": "",
                  "default": 1, "minimum": 0, "maximum": 1, "integer": true,
                  "options": [{"value": 0, "label": "本底"}, {"value": 1, "label": "有源"}]}],
  "devices": [{"id": "counter", "kind": "counter", "label": "β 计数器", "channels": 1,
               "calibration_parameters": [], "background_conditions": {"source_present": 0}}]
}
```

以上均为追加的可选字段；旧 Python 定义的构造位置参数不变。旧目录或历史存档缺少 `options`、`background_conditions`、`course` 时，分别按空选项、无本底识别规则和默认课程处理。读回历史存档使用存档自身声明，不从当前模块补推过去的本底身份。原始测量产品格式、数值工况和 CLI 设置语法不变。

可调增益的谱仪可声明 `Device("mca", "spectrum", "多道谱仪", 1024, calibration_parameters=("gain",))`，其中 `gain` 是实验已定义的参数。只列入会改变道址到能量映射的设置。工作台建立两点刻度时，取所选测量段的对应值。查看或导出不同增益的谱时，保留道址和计数，回到相同增益即可恢复能量轴。CSV 在不匹配的段将 `energy_MeV` 留空。测量 JSON 将这类刻度放在 `conditional_calibration`，读取者逐段比较 `conditions` 与 `settings` 后再换算。固定增益谱仪可省略该声明，仍可读写原有的 `nuclemu.calibration/1` 刻度文件。

### 本地会话的内存用量

会话保留每一秒已完成的采集窗及其不可变读数，停止或换工况时也会结清不足一秒的窗。导出后仍可按窗查看历史，因此导出不会释放这些记录。对 1024 道的 α 谱，600 秒固定工况的一次测量包含 600 个道谱元组；在 64 位 Python 的一次核对中，这些元组本身约占 4.9 MB，另有设置与测量记录开销。长曝光、多通道或同时打开多个实验时应按总窗数估计内存。界面按新增窗累计结果，刷新不会重复累计过去的读数。

## 仪器面板与结果

实验目录、暂停和变速控制有固定位置。装配多道谱仪的实验提供道谱面板，有适用刻度时允许切换横轴。装配计数器的实验提供计数表。来自不同实验的同型仪器复用面板；同场的两台同型仪器按实例区分。关闭面板只改变视图。切换实验时处理未保存结果，随后重新绑定面板，避免将新操作发送到先前的装置。

| 产品 | 建议导出 | 为解释数据应保留的内容 |
|---|---|---|
| 计数表 | CSV | 工况、通道、采集时长、原始计数、本底测量及曝光。净率可由各自按曝光归一的样品率和本底率求差。 |
| 道谱、标定谱 | CSV；图可另存 | 道址或物理轴、单位、每道计数、曝光、适用的刻度或筛选条件。 |
| 刻度 | 参考点表或结构化刻度文件，如 JSON | 通道、量程、参考点、映射函数及系数。保留原道址，便于应用另一份合适的刻度。 |
| 专用测量 | 按产品选择表或谱 | 例如 μ 子寿命的时间单位与接受窗，或穆斯堡尔透射谱的速度标定、扫描方向和各道曝光。 |

**共享刻度工具。** 学生可从目录的工具入口或谱工作区打开同一个刻度工具，用参考点建立并保存刻度，再重新载入并应用到通道、增益和量程均匹配的另一张谱。验收时逐道核对物理横轴是否符合保存的刻度函数，并切回道址轴，确认原始道址和每道计数均保留。

使用者可一次选取多个测量产品并分别选择格式，例如将样品谱和本底谱存为 CSV，将同次能量刻度存为 JSON。是否保留中间事件由实验需要的操作决定；用于重新配对的两个独立时标，无法从已经累计好的边缘谱恢复。
