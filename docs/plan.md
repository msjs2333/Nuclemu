# 本地实验工作台交付规划

[Web 工作台交互设计](web-workbench.md)规定学生界面的操作和验收场景。当前 α、β 实验的启动和操作见[本地浏览器实验台](gui.md)。[远景系列](vision/README.md)收录教师课堂、课程编排、档案与物理模型扩展的启用条件。

Nuclemu 的早期交付目标是一套可在学生电脑上离线使用的核物理实验工作台。使用者能选实验、调装置、采集和分析读数、导出结果，并在同一窗口进入下一项实验。实验作者能用公开编程接口接入自己的装置与模型。以下各项为计划交付内容。

| 顺序 | 工作内容 | 完成条件 |
|---|---|---|
| 实验框架 | 定义物理量、参考数据、装置实例、实验室时钟、采集与结果接口。交付本地模块发现机制、作者文档、计数与谱测量两个示例。 | 作者按文档安装独立示例模块，GUI 和 CLI 均能列出并运行。重复 ID、量纲错误、模型能力不足能定位到对应模块或参数。 |
| 工作台与命令行 | 提供统一实验目录、装置视图、设备面板、计时与采集操作。CLI 支持列出、校验、设置参数、按模拟时长运行和导出。 | 用同一组实验条件从两个入口采集。切换实验后，面板绑定新设备；关闭谱图时，已启动的采集继续。 |
| 12 个实验 | 实现计数、吸收、衰变、散射和谱学实验。按实验选择按窗计数、按道累计或关联事件模型，共享仪器和分析工具。 | 逐项完成目录里的测量任务；至少改变一项有效工况，用解析预期、参考数据或统计区间核对相应的可观测量。[逐项要求](experiments.md) |
| 结果交付与整体验收 | 允许按测量和产品选择要导出的表、谱、刻度及适用格式。验证本地运行、变速、普通重测和实验切换。 | 导出文件与屏幕上的同次测量一致。根据文件中的单位、时长、工况及所用刻度，能在另一台电脑上解释读数。 |

每个实验公开的操作都须有模型响应。例如，允许改变吸收片厚度，就要说明该厚度影响峰位、计数率或其他哪个量，并给出模型的有效区间。资料和模型可以支持更多操作，工作台只展示本实验采用的部分。涉及随机涨落时，用多次采集检查统计性质；固定种子和输入则用于检查显示、变速与批处理的一致性。

日常重测直接开始下一次采集。计算量由实验的观测目标决定，普通计数实验可按窗产生计数，能谱可按道累计。遇到确实依赖两路关联的测量，再使用能保留这种关联的数据表示。[框架与接口](architecture.md)
