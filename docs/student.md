# 学生实验手册

Nuclemu · **A Virtual Nuclear Physics Lab**

本册包含两门实验的原理、器材、测量步骤、空白记录表和思考题。先读所选实验的简介与目的，再按装置、仪器、记录和数据处理的顺序完成测量。工作台左栏“实验资料”读取下面相同的章节正文。

## 目录

1. [α 粒子在铝箔中的能量损失](alpha.md)：从参考谱建立刻度，跟踪加箔后的峰移。
2. [β 射线吸收](beta.md)：认识计数窗，测本底和样品，在本地求净率与吸收曲线。
3. [图形实验台操作](gui.md)：启动、采集、保存、下载与重开。

## 两门实验共用的记录习惯

每个测点保留源状态、材料规格和片数、实际曝光及原始读数。α 还要保留 ROI 与能量刻度；β 要保留窗号和所用本底身份。测得零次仍是有效测量，未测或未留存不能填零。

仪器“保存”留存当前读数，下载才生成可带走的文件。暂停和到限不自动保存。切换到资料页可继续采集；返回后先核对操作对象和当前状态。使用自己导出的数据填写空表，不把课堂示意或模型参数当作测量结果。
