## 阅读与验证顺序

先明确模型的物理量、单位和适用域，再核设备实例、输入、门和窗，最后核保存快照及导出读回。历史查看读取保存值，不重新抽样。种子之外还需记录设置与操作时间线；重开后的新轮次与旧记录具有各自的随机来源。

复验至少包含实际曝光、有效零计数、暂停续采、跨工况和手动保存。涉及文件必须导出并重开，逐道或逐窗核对，不能仅检查按钮成功提示。只验证课程函数不能证明 GUI、CLI 和文件链路已经接通。
