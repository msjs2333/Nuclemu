# 01 · 教师与学生的 Web 课堂

教师选择今天开放的实验和资料，学生从浏览器进入课程。教师可以展示同一台仪器给全班看，也可以让每名学生独立测量。这两种课堂行为需要不同的会话归属。

| 模式 | 谁掌握时钟、随机状态和仪器 | 通信内容 |
|---|---|---|
| 个人离线实验 | 学生机上的 Python 会话 | 本机浏览器提交操作、读取已采集的结果 |
| 教师演示 | 教师的一场演示会话 | 学生看到同一工况与同一批读数；默认只读 |
| 学生独立实验 | 每名学生设备持有自己的会话 | 教师发布课程版本、初始条件和课堂指令，学生在需要时交回指定的测量或档案 |

**推荐部署。** 教师机提供同一局域网可访问的课程目录和页面资源。学生独立实验的仿真与分析在学生设备执行；教师端承担分发和收集的开销。仅用浏览器进入时，可验证通过 Pyodide 在 Web Worker 运行 Python 模型。先在课机上测量首次加载、离线资源缓存及教师模块的依赖兼容性，再与本机 CLI 核对结果。使用本地 Python 服务的学生机仍可复用同一前端。[Pyodide Worker](https://pyodide.org/en/stable/usage/webworker.html)

**控制的边界。** 教师可以开放或结束一项任务，允许的装置操作由课程定义；学生在自己的会话内设置设备、开门采集和保存。若课程需要教师统一暂停，应让学生界面显示指令作用的会话及实际生效的仿真时刻。教师的演示会话保留独立入口，从演示切回个人实验时恢复个人读数。

**断线与收集。** 建议已加载的个人实验在短时断线时可继续采集并保存本机副本，教师界面显示最后收到的状态及时间。重新连接时按课程版本和测量身份补交；同一份结果重试提交应只产生一次有效收件。学生端要能区分“已保存到本机”和“教师已收到”。若课堂依赖统一指令，离线期间的有效操作由该课程明确约定。

**验证条件。** 两名学生同时打开 β 实验，分别改变箔片数，两人读数互不覆盖。教师演示 α 参考谱时，两名学生看到相同的演示谱。断开一台学生机后，其已完成读数仍可访问；重连前后另一台的物理时钟不变。集中托管全班独立会话是另一种候选部署，只有在学生端执行确有困难且教师机负载测试通过时再评估。
