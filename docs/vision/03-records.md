# 03 · 学生结果、教师档案与恢复

| 用途 | 使用者 | 需要保存什么 |
|---|---|---|
| 学生产品导出 | 学生 | 自选计数表、道谱、刻度等产品和各自格式；带单位、实际曝光、工况及设备身份 |
| 保存实验以便重新查看 | 学生 | SQLite 存档时的设置与运行状态、各轮参数和变更、学生已保存的快照及其关联，读回后可复查同一份数据。具体范围见[实验文件设计](../measurement-workflow.md) |
| 教师整场档案 | 教师查阅与导出 | 课程与模型版本、各轮有效设置和变更、实际曝光、学生已保存的原始观测及分析引用 |

比如学生已保存一份本底和三次样品测量，并用该本底修正三次样品测量，教师档案应指向同一份本底计数及其曝光，保留各样品的原计数和曝光，能重算各自净率。α 课则需保留道谱、参考点和所用刻度。常规计数课保存窗内整数计数即可；只有课程允许重新做事件配对时才需更底层的时标。教师专属的模型真值须单独控制访问，不混入仪器的可观测量。普通文件的校验值可用于检查损坏，可信考核若要验证提交身份和数据出处，须另行定义信任边界。

**历史、重放与续跑。** 打开历史记录使用已保存读数。精确重放需固定模型版本、数值环境、种子和操作时间线，改变显示刷新率或批处理分块后结果仍应一致。跨版本比较可按实验规定统计等价准则。要从任意时刻继续同一随机过程，还需保存时钟、生成器状态、未结清的采集窗、模型内部状态等；已存谱可用于重新分析，不能据此推定能够精确续跑。

先验证一名教师能否只用档案复算学生的指定结论，再决定是否增加更多记录。事件率和规模确有需要时才评估专用容器。数据缺失、模型近似和界面掉帧分别记录其影响；容量不足时应显式处理，保持已完成记录可解释。
