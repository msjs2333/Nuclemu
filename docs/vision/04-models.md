# 04 · 物理模型与仪器扩展

实验公开的可观测量决定模型的计算粒度。按窗计数、分道谱、带时标的事件和波形可按需接入同一会话。定义模型时应写清覆盖的测量阶段、已经包含的效应、有效工况和可变参数。例如固定几何下的经验计数率已包含探测效率，在下游再乘同一效率会重复扣除。切换模型后才可开放其新支持的操作。

| 课程需求 | 模型边界 | 可验证的例子 |
|---|---|---|
| 多台仪器读取同一信号 | 分流共享输入的随机实现；独立噪声留在对应仪器 | 理想无损分流的两个相同计数窗应逐窗读到相同整数 |
| 符合窗与寿命 | 用仪器可观测的时标、门宽和甄别条件处理配对 | 改窗后可按已保存的独立时标重算；只有边缘谱时应说明缺少配对信息 |
| 相对论时间效应 | 实验室时钟统一排序，模型在明确参考系内计算飞行时间或粒子固有时，再映射回实验室时刻 | 恒速运动的寿命模型在静止极限回到静止寿命，仪器曝光另行结算 |
| 相干演化与测量 | 模型持有量子态，可采用自己的内部步长，控制变化和物理测量在会话时刻生效 | 查看已有读数不更新态；课程明确施加的测量按其规则产生结果并更新状态 |

材料、核素、谱线或响应表携带单位、出处、版本和适用域。仪器读出的能量、通量或计数率应保留各自的物理含义。端口类型相容之后还需核对效应是否重复、数据粒度是否支持课程的后续操作。

新实验若需要窄时间窗、长会话或高事件率，用代表性的曝光和保留时长测试时间分辨率、内存与磁盘。存储格式、求解器和波形链路按实测需要选择；普通知识点可继续使用聚合模型。真实仪器接入单独评估。
