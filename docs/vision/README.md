# Nuclemu 远景系列

这里收录需要课堂试用或新物理实验来验证的设计方向。近期本地工作台的范围见[交付规划](../plan.md)，学生页面与保存流程见 [Web 工作台设计](../web-workbench.md)。以下篇目以需求出现的条件组织，编号只用于引用。

| 篇目 | 何时值得推进 | 应拿什么验证 |
|---|---|---|
| [01 教师与学生的 Web 课堂](01-classroom.md) | 同一门课需要集中分发、演示或收集结果 | 两名学生独立调节工况，教师演示和短时断线都保留各自的数据 |
| [02 课程编程与教学活动](02-courses.md) | 教师要改变开放操作、换用模型或给出不同任务 | 用公开接口发布一门课程，目录和仪器面板可直接识别 |
| [03 学生结果、教师档案与恢复](03-records.md) | 教师要查阅结论依据，或学生需要恢复较长实验 | 从保存的资料重算结论，说明能否读回、重放及续跑 |
| [04 物理模型与仪器扩展](04-models.md) | 新实验的可观测量依赖符合、时间关联或相干演化 | 用该实验的实际操作和物理极限核验所需模型 |

各方向可独立采用。课程先通过编程接口定义，本地教学保持可用。班级管理、可信考核、复杂存储和真实仪器接入均需另有具体使用场景。
