# 02 · 课程编程与教学活动

教师应能用受文档支持的编程接口复用实验、改装装置或替换模型。课程定义决定哪些实验可见、学生能调哪些参数、有哪些测量产品和配套资料。模型能力可以超出课程开放范围；每个开放操作都须有相应的物理响应。

以 β 吸收为例，一门课可以固定几何，只开放片数和本底测量；另一门课若要讨论距离，应先接入支持距离变化的模型。实验作者提供有效参数范围、单位、设备实例和一组可重复测量的工况。作者文档应覆盖创建定义、安装、发现、运行、导出与定位错误，使有编程基础的教师可以独立验证改动。可视化课程编排放在调课任务已有稳定做法之后设计。

若教师需要记录本、反馈或评阅，可把学习目标关联到可检查的证据。例如让学生选择本底测量时间，解释净率及其不确定度，再说明低计数点的结论范围。普通重测仍直接开始新一次采集；课程可在确实需要学生解释某次补测时收集说明。随机涨落允许使读数偏离期望值，评阅应同时检查工况、方法和解释。

盲样参考值和讲评提示由教师选择是否发布。课堂管理只引用课程、测量段和学生提交的产品，不改变测量值。启动图形化编排或评分功能之前，应先由教师按编程方式独立完成一次课程修改，记录实际遇到的问题。
