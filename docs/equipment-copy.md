# 器材与操作文案

本页供工作台接入器材介绍和帮助提示。介绍先解释器材作用，材料规格和片数放在操作面板；课程限制在教材与技术参考中说明。

| 器材 | 学生介绍 |
|---|---|
| 源座 | 源座固定放射源的位置。装入源后，粒子沿装置方向传播；取下源可以观察没有源信号时的读数。β 实验保持探测输出开启可测环境本底。 |
| 箔架（α） | 箔架把薄箔固定在放射源和探测器之间。先用空箔架采谱，再放入铝箔，观察同一条谱线的峰位怎样移动。 |
| 箔架（β） | 箔架把薄箔固定在放射源和探测器之间。先测空箔架，再增减铝箔，在相同探测条件下比较透射计数率。 |
| 硅探测器 | 硅探测器将粒子沉积的能量转换为电脉冲，脉冲幅度用于区分粒子能量。开启输出后，信号送到多道谱仪；采集还需在谱仪上开始。 |
| β 探测器 | 探测器将探测到的粒子转换为计数脉冲，送给计数器。开启输出后，还需在计数器开始采集；A/B的曝光时间可分别设置。 |
| 多道谱仪 | 多道谱仪按脉冲幅度把计数分入各道，形成能谱。选择一条孤立峰，可以读峰心并建立能量刻度。 |
| 计数器 | 计数器在开门期间累计输入脉冲。本课 A 在左、B 在右，表示同工况下分别取样的两组虚拟重复观测。整机开始或暂停同时控制两窗；每窗显示整数计数和单次实际曝光，窗长可分别设置。 |

学生界面统一使用“实验记录”“道谱”“计数记录”“能量刻度”。“保存”留存按键时可读的快照；“导入记录”加入本场缓存；“载入测量数据”替换当前仪器的测量数据，β一次处理两窗；“保存实验”下载整场文件。不要用同一句“载入成功”混淆作用范围。
