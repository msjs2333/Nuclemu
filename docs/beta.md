# β 射线吸收

## 实验简介与目的

本实验在固定装置中测量空源本底与有源透射计数，比较铝箔面密度改变时的吸收趋势。

通过两窗虚拟重复观测，学习记录整数计数与实际曝光，在本地计算净计数率及不确定度，区分统计涨落和变化趋势。

## 原理与测量量

β 粒子在材料中损失能量，部分粒子不能再到达探测器或满足探测条件。本课测量固定几何和探测条件下的计数响应，不测单个电子的能量或轨迹。真实透射曲线只在部分区间近似指数衰减，不能把任意厚度处的计数规律当作普遍定律。[CAEN β 透射教学实验](https://edu.caen.it/experiments/nuclear-physics/beta-radiation-transmission-through-matter/)

比较不同测时的测量时，先用计数除以实际曝光得到计数率。空源座时的环境本底也随曝光累计，样品与本底必须各自归一后再相减。计数是整数，实际曝光单位为 s，计数率单位为 s⁻¹。

## 器材与接线

粒子路径为 **β 源 → 箔架 → 探测器**，电缆将探测器输出接到**一台计数器**。本虚拟课程的 A、B 两窗代表相同装置条件下的两组重复观测，按同一平均响应分别取样；这不是把同一电缆上的一次真实脉冲抽样两次。面板左侧为 A、右侧为 B，各窗大计数下方可设单次曝光。整机只有一组“开始测量／继续测量”和“暂停测量”，同时控制两窗；保存、清空和载入均一次处理A/B，右栏设置整机共同采集模式和目标。

| 器材 | 作用与本课可观察量 |
|---|---|
| 源座与 β 源 | 源座固定源的位置。装源测样品，取下源而保持探测输出开启可测环境本底。 |
| 箔架与薄箔 | 箔架把薄箔固定在源和探测器之间。增减铝箔，在相同条件下比较透射计数率。 |
| 探测器 | 将探测到的粒子转换成计数脉冲；输出开关控制送到计数器的信号。 |
| 计数器 | 在开门期间累计输入脉冲。每窗给出实际曝光和整数计数，便于比较不同测时的涨落。 |

新实验从空源座、空箔架开始。本课提供 50 或 100 µm/片的铝箔（Al），可装 0–24 片；默认规格为 100 µm/片。总厚度为单片厚度乘片数。固定几何下不调距离，不另计算空气路径损失。50 µm两片与100 µm一片的总厚度、面密度相同；比较两种规格时先换算面密度。本课主要比较0–0.4 g/cm²，超过此范围的允许设置属于教学外推，不能用来判断真实材料的射程。

装置动画只帮助辨认当前器材状态，散开的源束和空气中的少量背景点均为视觉示意，与真实计数完全无关。它们不表示实际粒子轨迹、散射角或脉冲；本底必须通过空源、探测输出开启的计数测量取得，不能数动画点代替。

| 状态 | 如何解释读数 |
|---|---|
| 空源，探测输出开，计数窗开门 | 可取得环境本底；短曝光也可能测得零次。 |
| 有源，空箔架，探测输出开，计数窗开门 | 无附加箔参考，同时包含环境本底。 |
| 探测输出关，计数窗开门 | 实际曝光仍累计，输入为零；不能代替本底测量。 |
| 整机暂停 | 两窗均停止累计，各自的已有读数与实际曝光保留。 |

## 先认识逐窗读数

1. 在装置页开启探测输出，打开“计数器”。在 A 列大计数下把单次曝光设为 1 s，在 B 列设为 5 s，按“开始测量／继续测量”同时启动两窗。各列单次曝光决定本窗逐次出数的间隔，右栏定时目标则限制本轮累计曝光。
2. A 逐秒出现新行，B 在自己的 5 s 曝光后出现一行。大数字显示最近完整曝光窗的计数，列表保留窗号、实际曝光和整数计数。尚无完成窗与已测得零次不同。
3. 按“暂停测量”，两窗同时停止。手动暂停可取得不足设定窗长的部分窗读数，填写实际曝光。再按“开始测量／继续测量”，从两窗各自已有曝光和计数接着测。保存、清空或载入时按整台计数器操作，不必选择A/B。
4. 保存一次保留两窗数据，命名后从实验记录下载，按A/B身份逐行核对。相同工况和曝光下，两组读数有相同的期望值，但分别取样，允许偶然相同。A 的五个短窗之和不必等于 B 的一个同期长窗，也不要求两者必须不同。

## 取得吸收曲线

1. 取空源座、开启探测输出。设置两窗后用“开始测量”测独立本底，可先取 30 s 曝光；暂停或到限后，一次保存两窗读数，记下名称和各自实际曝光。可固定用 A 的记录处理吸收曲线。
2. 为新测点清空整台计数器，装入 β 源，选 100 µm/片、0 片。在仪器设定定时采集 5 s，用“开始测量”采集，保存无附加箔参考。保存和清空均同时处理两窗。
3. 依次测 1、2、4、8、12、14 片，每点一次保存两窗读数、整机清空后重新开始测量。保持几何与探测设置不变；厚箔处可延长曝光。暂停和到限均不自动保存。
4. 从“实验记录”下载本底和各样品的 CSV 或 JSON，使用整数计数与各自实际曝光，在本地计算净率和不确定度。工作台不提供本课的本底扣除结果。
5. 下载整场实验，在另一会话载入后核对保存值，再用自己的文件填表。缺少样品或本底依据时注明缺项，不从模型参数补算测量值。

同一测点、同一组观测内，可合并互不重叠且工况相同的逐窗计数：总数与总曝光分别求和。A、B 是两组虚拟重复观测，应分别保留身份。不要把同一组同轮 3 s 与 5 s 的累计快照相加，后者已包含前者。

Al 密度取 2.70 g/cm³，面密度 `m = 2.70 × 单片厚度(µm) × 片数 × 10⁻⁴ g/cm²`。面板若显示 mg/cm²，除以1000再填入表中的 g/cm²。

样品计数与曝光记为 `Ns, ts`，独立本底记为 `Nb, tb`：

```text
总计数率 = Ns / ts
净计数率 = Ns / ts − Nb / tb
u(净率) ≈ sqrt(Ns / ts² + Nb / tb²)
```

`u` 为独立泊松计数代入传播公式的近似标准不确定度，单位 s⁻¹。低计数时“净率 ± u”不是精确置信区间；零计数项代入得零也不能证明真实方差为零。负净率保留原值。

## 结果讨论与思考题

以面密度为横轴、净率及标准不确定度为纵轴作图，保留零和负值。比较薄箔处的快速下降与厚箔处的缓变，检查单一指数是否能覆盖整个测量范围。可由净率降到无箔净率一半处估计本装置的有效半值面密度，但不能把不同区间强行拟合成同一衰减常数。低计数或负净率不能直接取对数后丢弃。有效半值面密度与固定装置有关，不等于电子最大射程。

1. 为什么空源本底不能用关闭探测输出的测量代替？
2. 曝光不同，直接相减整数计数会出现什么问题？
3. 加箔后一次读数偶尔升高，是否足以否定吸收趋势？还需检查哪些量？
4. 为什么同一组同轮累计快照不能当作独立重复测量？本课 A、B 两组读数为什么既可能不同，也可能偶然相同？
5. 多个样品共用本底时，各净率为什么存在相关性？

## 保存、载入与带走数据

仪器“保存”一次保留A/B按键时可读的逐窗数据，名称可接受预填值或修改；续采不改旧记录。两窗行数可以不同。表中已有整数计数的部分曝光也按实际值保存，不补成完整窗；大读数尚无完整窗时仍显示“—”。真正0 s且无读数的一侧留空，不造记录。整机清空可选“保存并清空”“直接清空”或“取消”。“实验记录”的“导入记录”只增加缓存；仪器“载入测量数据”才整体恢复两窗当前读数，任一侧非空先确认一次覆盖；取消或文件无效时两边原读数均保留。历史单窗文件仍可读取或导入记录；载入仪器时自动按文件所记A/B恢复该窗，另一窗原样保留，无须选窗或配对。新版整机文件始终恢复整机，明确缺测的一侧留空。

在“实验记录”勾选并“导出所选”，下载单项或多项记录；“下载整场实验”或“文件 → 保存实验”带走 `.nuclemu`，包含全部已留存记录、末态和轮次。未手动保存的一轮可有曝光元数据，但没有已存原始读数，不能填零。确认文件已下载后再退出。重开待机；从旧值续采前，先在仪器载入测量数据。
