# β 射线吸收

实验 `beta` 的虚拟源和计数器 `counter` 位置固定，铝箔在两者之间。分别测量本底、无附加铝箔的参考读数和几个不同厚度的读数。由净计数率随面密度的变化，估计该装置的有效半值厚度。

## 怎样取得一条吸收曲线

| 工况 | 参数 | 建议曝光 | 记录 |
|---|---|---|---|
| 本底 | `source_present=0` | 60 s | 本底计数及其曝光 |
| 无附加箔 | `source_present=1`，`foil_count=0` | 20 s | 固定几何下的参考计数 |
| 有附加箔 | 保持有源，依次设 4、8、16 片 | 每次 20 s | 各厚度的计数及其曝光 |

每个测点在固定工况下采集。把同一测点各窗的整数计数相加，同时把各窗的实际曝光相加，再计算计数率。厚箔处净率较低，可延长测时，提高该点的统计精度。

设样品和本底的计数、曝光分别为 `Ns, ts` 和 `Nb, tb`。净率为 `Ns/ts − Nb/tb`，独立泊松测量的一阶标准不确定度估计为 `sqrt(Ns/ts² + Nb/tb²)`，两者单位均为 s⁻¹。偶尔得到的负净率也属于测量结果，应保留原值。多个测点共用同一份本底时，任意两点净率的协方差估计为 `Nb/tb²`。计数很少时，上述标准差估计只作参考。

## Web 工作台操作路径

1. 在实验目录找到“β 射线吸收”，先点“查看资料”，再“进入实验”。在“实验装置”页，沿 β 源座、铝箔架、β 探测器到计数器查看粒子路径和信号连接。
2. 点击“β 源座”，将“测量模式”设为 **0（本底）**，点“应用参数”。点击“铝箔架”可设置箔片数，范围为 0–24，每片厚 0.10 mm。本底测量不受箔片数影响。
3. 点击“计数器”或部件说明中的“打开β 计数器”，进入“测量仪器”页。确认设备为 β 计数器 `counter`，打开顶栏“采集”，选择“定时”并输入本底曝光秒数，返回仪器，点“开始采集”，等采集门关闭。记录整数计数与实际曝光。
4. 返回装置页，将源座设为 **1（有源）**、铝箔架设为 **0 片**，分别应用参数。返回计数器，开始新的一次定时采集。再依次设置 4、8、16 片，每次在上一采集结束后改工况、重新开门。不同测点可以使用不同曝光。
5. 在顶栏“分析”的“本底记录”中明确选择第 1 次的无源测量。对照各样品行的片数、实际曝光、整数计数、计数率、净率及其标准不确定度。本底自身是参考。样品净率使用各自曝光归一后再扣本底。
6. 在“实验记录”页选择要保留的本底和样品产品，分别选择 CSV 或 JSON 后“导出所选产品”。需要以后在工作台查看整场测量时使用“保存整场实验”。退出前确认需要的记录已保存；尚需继续测量时选择“继续实验”。

仪器读数只包含已完成的曝光窗，定时结束会结清最后不足一秒的窗。页签切换只改变视图；“暂停”冻结仿真时间，“停止采集”则结清并关闭当前采集门。更改工况前等当前测点结束，便于每次开门对应一个厚度。不要把总仿真时间当作某个测点的曝光。

## 保存测量结果

选定计数器，将本底和样品读数保存为 CSV 或 JSON。每次开门单独记录，同一采集内工况相同的相邻曝光窗会合并。CSV 的 `counts`、`exposure_s` 和 `settings` 分别给出计数、实际曝光及源和铝箔设置。计数器只有通道 0，`energy_MeV` 为空。JSON 在各段的 `readings.counter[0]` 中保存计数，曝光由 `end_s − start_s` 得到。[图形实验台](gui.md) · [命令行](cli.md)

导出保留总计数，分析时选择本底段和相应的有源段，用 `results.net_count_rate(Ns, ts, Nb, tb)` 计算净率和标准不确定度。零计数可正常导出；各段曝光不同时，应分别使用各自的曝光计算。

## 接入与读数验收

装置元数据将源座 `source` 绑定到 `source_present`、箔架 `foil` 绑定到 `foil_count`；探测器 `detector` 和计数器 `counter` 均指向同一读出设备 `counter`。按此绑定设置参数，使用同一随机种子和相同开门、改工况时间线时，Web 与 CLI 应得到相同的原始计数及实际曝光。

以下命令在一个新会话中依次采集五次，以第 1 段作本底；每个 `--step` 独立开关一次采集门。跨行命令可合并成一行执行：

```text
python -m nuclemu run beta --seed 42 --device counter
  --step 19.5,source_present=0,foil_count=0
  --step 7.25,source_present=1,foil_count=0
  --step 7.25,foil_count=4
  --step 20,foil_count=8 --step 20,foil_count=16 --background 1
```

| 测点 | 片数 | 实际曝光 / s | 计数 | 净率 / s⁻¹ | 标准不确定度 / s⁻¹ |
|---|---:|---:|---:|---:|---:|
| 本底 | 0 | 19.5 | 32 | 参考 | — |
| 无附加箔 | 0 | 7.25 | 720 | 97.669319 | 3.712430 |
| 样品 | 4 | 7.25 | 402 | 53.807250 | 2.780682 |
| 样品 | 8 | 20 | 565 | 26.608974 | 1.223379 |
| 样品 | 16 | 20 | 222 | 9.458974 | 0.799472 |

更改随机种子、曝光或开门顺序时，所得整数计数及其统计不确定度也会变化。

## 从曲线估计半值厚度

每片铝箔厚 0.10 mm，允许 0 至 24 片，铝密度取 2.70 g/cm³。以附加面密度 `m = foil_count × 0.010 cm × 2.70 g/cm³` 为横轴，以各段净计数率及其不确定度为纵轴作图。找出净率降至无附加箔读数一半时的面密度 `H`，也可用 `S(m) = S₀ × 2^(−m/H)` 对各点估计 `H`。低计数测点可能波动到零以下，仍保留在原始计数率图中。

本实验用有效指数曲线描述固定几何、固定探测阈值下预过滤 β 束的计数率。连续 β 谱中的低能粒子和散射可改变真实薄层测量的曲线形状。估计的半值面密度只适用于此装置及其厚度区间，不能直接外推至裸源或用于确定电子的最大射程。[CAEN 的 β 透射实验](https://edu.caen.it/experiments/nuclear-physics/beta-radiation-transmission-through-matter/)

教师备课或核对模型实现时可查阅[教师与模型作者参考附录](model-reference.md#beta)。
