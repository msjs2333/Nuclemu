# β 射线吸收

## 简介与目的

在固定的源、铝箔和探测器几何下，测量 β 射线透射计数随铝箔面密度的变化。先用同一探测输入的两台计数器认识曝光窗，再用空源座测量本底，比较扣除本底后的吸收曲线。

完成实验后，应能区分探测器输出与仪器采集门，按实际曝光比较不同测时的读数，保留原始整数计数与本底引用，并用自己保存的记录估计该装置的有效半值厚度。

## 认识器材和读数

源座可放入 β 源，也可置空。Al 箔架可选 50 或 100 µm/片，装入 0–24 片；默认 100 µm/片，0 片为空箔。总厚度为单片厚度乘片数。计数器 A、B 连接同一探测器输出，各有独立的采集门。

| 状态 | 可观察的结果 |
|---|---|
| 空源座，探测器输出开，仪器采集 | 可以测到环境本底；空源不等于关闭探测器。 |
| 有源，空箔，探测器输出开，仪器采集 | 取得无附加箔的参考读数。 |
| 探测器输出关，仪器采集 | 有实际曝光，输入为零；不能把这份零输入记录当作环境本底。 |
| 探测器输出开，仪器未采集 | 物理时间可以继续，关闭采集门的仪器不累计曝光。 |

计数是整数，曝光单位为 s，计数率单位为 s⁻¹。曝光指该仪器实际开门的累计时间，不是实验室时钟、等待时长或预设值。源座和箔架在装置页调整；选择本底属于实验分析，不改动源或仪器中的原始计数。

## 选择曝光窗

先记录设备身份、窗的起止时刻和已保存记录名称。安排 A 与 B 同起点采集，A 取两个连续 5 s 窗，B 取一个 10 s 窗。A 第一窗结束后保存，再只清空 A，重新开始第二窗；B 继续。第二窗和 B 长窗结束后分别保存。

只有 A 的两窗无间隙、无重叠且恰好覆盖 B 的长窗时，才核对 `N_A1 + N_A2 = N_B`。如果操作等待造成时间间隙，照实登记窗口，不能把不同时段强行相加。同步时间线的安排由课堂操作说明给出。

另做一次 A 在 5 s 后不再开始的测量，观察 B 是否继续到 10 s。未开启的 A 第二窗记“未测”，不要填成零计数、零计数率。零计数必须伴随真实的有效曝光。

| 已保存记录 | 设备 | 开门时刻 / s | 关门时刻 / s | 实际曝光 / s | 整数计数 |
|---|---|---:|---:|---:|---:|
|  | A 第一窗 |  |  |  |  |
|  | A 第二窗 |  |  |  |  |
|  | B 长窗 |  |  |  |  |

窗口是否恰好覆盖：______；`N_A1 + N_A2 − N_B`：______ 次。若不相等，先检查设备、输入、工况与窗边界，再解释读数。

## 怎样取得一条吸收曲线

1. 保持几何和仪器设置不变，在装置页移空源座，打开探测输出。用所选计数器测量并保存独立本底，记录其曝光。
2. 放入 β 源，箔片数设为 0。为新测点保存前一读数、清空当前仪器，再开始采集，保存无附加箔参考。
3. 选定单片规格，逐步增加片数，例如默认规格下测 4、8、16 片。每个测点保持工况不变，分别保存计数和实际曝光。厚箔处可延长测时。
4. 在本底分析中明确选择适用的空源参考，核对它的设备、来源、源座状态和曝光。若重测过本底，可换一份参考，观察净率变化并确认原始计数和曝光没有改变。
5. 下载需要的已保存记录及其分析依据。重开后用文件中的读数填表，不从模型参数补算缺失的测量；找不到对应本底时标记“缺本底依据”。

可先选本底 60 s、无箔和各厚度 20 s，按计数水平调整。计数有统计涨落，不能要求每次加箔后的单次读数都严格下降；比较总计数前应先核对曝光。

## 计算与记录表

样品计数和曝光记为 `Ns, ts`，本底记为 `Nb, tb`。先分别归一，再相减：

```text
总计数率 = Ns / ts
净计数率 = Ns / ts − Nb / tb
u(净率) ≈ sqrt(Ns / ts² + Nb / tb²)
```

`u` 是独立泊松计数代入传播公式的近似标准不确定度，单位同为 s⁻¹。计数很少时不能把“净率 ± u”当作精确置信区间。扣除后为负的净率保留原值，不改为零。

## 从曲线解释结果

以面密度为横轴、净计数率及其标准不确定度为纵轴作图，保留零值和负值。由净率降到无附加箔读数一半时的位置估计有效半值面密度；也可在适用区间拟合 `S(m) = S₀ × 2^(−m/H)`。低计数或负净率不能直接取对数后丢弃。

同一输入的同期 A、B 共享计数；同轮的重叠累计快照也可能包含同一批计数。它们不是相互独立的本底和样品，不能直接代入上面的独立误差公式。独立、适用的空源测量才用于课程的常规本底扣除。

本实验估计的是固定几何和探测条件下的有效吸收曲线，不能直接外推成裸源的普遍衰减规律或电子最大射程。真实 β 透射曲线在不同厚度区间可偏离简单指数近似。[β 透射实验原理参考](https://edu.caen.it/experiments/nuclear-physics/beta-radiation-transmission-through-matter/)

## 保存、清空与带走数据

仪器上的保存复制当时可读数据进入本场缓存，后续采集不改写该记录。3 s 和 5 s 保存的累计记录可能重叠，应保留各自身份。主动清空有读数的仪器时，选择保存后清空、直接清空或取消；先确认当前操作的是哪台仪器，另一台可继续采集。

本底与样品都应主动保存，并保留各自实际曝光和引用关系。整场文件还保留设置、轮次和已缓存记录；未保存的读数不会因退出或下载整场而自动补存。

1. 在“实验记录”中勾选已保存记录、选择 CSV 或 JSON，再点“导出所选产品”，带走需要的单项数据。
2. 要保留整场设置、全部已保存记录及本底引用，点“下载整场实验”，保存 `.nuclemu` 文件；“文件”菜单中的“保存整场实验”也会下载该文件。
3. 退出时若选择下载整场实验，先在浏览器中确认文件已保存，再点“文件已保存，退出”。取消下载、下载失败或尚未确认文件时，返回实验继续处理。本场缓存应下载成文件带走。
4. 在另一会话的实验目录顶部点“打开实验文件”，选择保存的 `.nuclemu`。先核对已保存记录的设备、源座、单片规格、片数、实际曝光、整数计数和本底选择，再填写本页空表。仪器当前曝光从零开始，门与探测输出关闭；历史读数仍在计数记录表中。

更多入口说明见[图形实验台](gui.md)。本页的选窗、计数与曝光口径以[采集与保存约定](measurement-workflow.md)为准。
