# β 课程：单台计数器双窗与逐窗文件

本页供课程、GUI、CLI 维护者复核模型和读数；学生与教师正文由相应教材维护。界面交付见[工作台验收](workbench-acceptance.md)，公共边界及文件规则见[测量工作流](measurement-workflow.md)和[可携实验文件](exchange.md)。

## 装置、端口与旧记录

| 对象 | 稳定标识 | 物理作用与允许操作 |
|---|---|---|
| 源座 | `source`，`source_present` 默认 0 | 0 空源、1 装源；空源开探测输出时仍可测环境本底。 |
| 箔架 | `foil`，`foil_count=0`，`foil_spec_um=100` | 0–24 片 Al，单片 50/100 µm；空箔与空源分开。 |
| 探测器 | `detector`，输出 `beta_detector` / `beta_detector_b` | 学生端一个探测输出开关共同控制两组虚拟观测，不因关闭电输出而关闭物理源发射。 |
| 计数器 | 一个 `counter` 装置部件 | `device='counter'` 保留主入口，`devices=('counter','counter_b')` 绑定同台仪器的 A/B 两窗。 |
| 窗 A / B | `counter` / `counter_b` | 同工况、同一平均响应下分别取样，各自设统计窗长和目标；学生面板一组开始／继续、暂停同时操作两窗。 |

两个底层设备 ID 是稳定读数目标，不代表装置中放了两台仪器。学生面板 A 左、B 右等宽并列，各窗参数在自身大读数下方。GUI 按部件的 `devices` 读取分组，不按课程 ID 或显示文字猜测。装置图保留探测器到计数器的一条电信号连接；模型的两个输出用于表示虚拟重复观测，不代表增加一条物理电缆。独立设备复用应另用测试课程验证，不能改画本课装置。

整机调用 `Session.start_group(component.devices)` / `stop_group(component.devices)`，同一物理时刻一次结算并共同开／关门，按各窗既有预设开始或继续各自轮次。操作先校验全组，任一目标不合法或清空确认未完成时整体拒绝，不得只启动一半。不用 `device=None` 代替明确范围，以免联动另一台仪器。探测输出不随整机启停改变；学生保存、清空和载入均以整台计数器为范围，不增加选窗或跨文件配对步骤。底层独立门接口供模型及专用核验使用，不再描述为学生页逐窗启停步骤。

已有文件保留其保存的设备、设置及读数。已识别的旧整场文件恢复原本底2 s⁻¹、无箔净率100 s⁻¹的单指数响应，并保留文件声明的共享输入或独立重复观测关系；重开续采不静默改成当前响应，应核对其历史模式说明。单项旧记录载入当前课程时，已存计数与曝光保留为固定前缀，新增曝光采用当前分别取样模式，不把历史整场模型一并切入。历史单窗载入按文件所记设备自动恢复该窗，另一窗不变；新整机文件按完整范围恢复，明确缺测的一侧留空。旧 `counter` 映射 A，`counter_b` 映射 B；没有B记录不补造，也不提供跨文件配对流程。缺单片规格的旧 β 模型按原来 100 µm/片解释，不以新默认设置重算原始计数。没有逐窗数据的旧累计记录，只能作为旧累计观测，不能从总数拆造五行。

[ORTEC 995 说明](https://www.ortec-online.com/-/media/ametekortec/brochures/9/995-a4.pdf)可作为一台模块内 A/B 计数及门控的器材参考；本课左右同时显示、每窗独立窗长及整机共用启停属于明确的教学约定，不声称该型号具有本课全部 UI 行为。[ST260 手册](https://www.spectrumtechniques.com/wp-content/uploads/ST260-Manual.pdf)第 19–21 页区分显示计数和带经过时间的测量数据。本课具体操作以公共采集协议为准。

## 模型、单位和粒子流显示

课程函数 `expected_rates(settings)` 与 `sample_counts()` 共用同一均值计算：

```text
总厚度 / µm = foil_spec_um × foil_count
m / (g·cm⁻²) = 2.70 × 总厚度 / µm × 10⁻⁴
S = source_present × [10000 exp(−39.5m) + 1600 exp(−2.2m)]  (s⁻¹)
R = S + 50  (s⁻¹)
N_A ~ Poisson(R × A的区间实际曝光)
N_B ~ Poisson(R × B的区间实际曝光)
给定工况下两组分别取样
```

11600 s⁻¹是零箔的有效净率，50 s⁻¹为环境本底。两项仅为课程经验响应，不归因为某种核素、散射或光子成分。固定几何、源窗和探测效率已合入，不是源总活度，不另乘距离效率或空气损失。`source_present=0`只移除源相关项；电输出关闭时，框架把送入门的输入置零而保留开门曝光。

课程校核范围为0–0.4 g/cm²。现有规格与0–24片控制保留，100 µm规格15片起超出范围，扩展到24片的0.648 g/cm²仅为教学外推；50 µm规格24片为0.324 g/cm²。必须按总面密度比较两种规格，不能把允许操作范围当作已核实范围。
[CAEN β 透射实验](https://edu.caen.it/experiments/nuclear-physics/beta-radiation-transmission-through-matter/)支持逐层加吸收片比较计数率，并指出近指数透射只适用于部分曲线区域。本课用双成分经验响应表示前段与厚端的不同变化，不把整段压成单一半值面密度；不能据此推导完整β能谱、单粒子射程、散射角或材料内停止点。

`particle_flow(settings)` 是纯模型状态函数，绑定到 `Experiment.particle_flow`，由 `Session.particle_flow` 提供给界面。它不调用随机数或推进时间，返回：

- 公共字段 `kind`、`material`、`thickness_um`、`areal_density_g_cm2`。
- `incident_rate_s`、`transmitted_rate_s`：上述固定几何有效信号率，供模型核对；不可标注为绝对粒子流或源活度，也不对应画面点数。
- β 专有 `transmission`、`background_rate_s`。环境本底不画成源座发射的粒子。

装置画面的扇束及空气背景点只表示源、材料、探测等状态，与真实计数无关；示意点既不是探测脉冲，也不是按曝光累积的单粒子记录。不能数点复算仪器读数，也不承诺画面疏密与计数率成比例。扇束不是从平均透射推导出的单粒子散射角，点的消失也不代表测得材料内停止位置。

源存在时，关闭电输出只关闭可测电信号，不能抹去源状态；空源时源信号率为零，环境本底仍按模型测量。加箔改变真实模型的透射均值，学生应从计数器原始读数和实际曝光检验趋势。空气背景点不参与泊松抽样或本底扣除，当前模型的50 s⁻¹本底不由动画产生。动画开关、帧率和重复读取状态函数均不得改变同一测量操作线的计数。

## 输入与抽样关系

本课 A、B 表示同一装置条件下的两组虚拟重复观测，类似重复做两次实验。A 绑定 `beta_detector`，B 绑定 `beta_detector_b`，按同一平均响应分别作泊松抽样，包含各自的环境本底涨落。学生端一个探测开关共同控制这组输出；整机开始、继续和暂停共同控制两窗。这里不模拟把同一电缆上的真实事件抽样两次。

给定工况下两组抽样相互独立，同曝光的期望计数相同，实得整数可以不同，也可以偶然相同。A 的五个短窗之和不必等于 B 的同期长窗，不能要求必须相等或必须不同。随机课程核验逐行曝光、整数、设备身份与工况。同一组内的重叠累计快照、载入旧记录后共享的前缀仍不能按独立观测处理。

公共框架的真实共享输入语义保持不变：多个设备绑定同一个输出时，只抽样一次并无损分发同一批计数。其已知输入、错开门等专用测试核验真实分接与门边界，不用本课分别取样的教学约定改写公共路由。

模型只有区间计数，没有每个脉冲的到达时刻。同一设置、种子和操作时刻下刷新频率与推进批次不应改变结果；改变门或工况的真实生效时刻可能改变抽样区间，不能承诺另一时间线仍沿用同一个潜在事件序列。

## 五个短窗、一个长窗与热调工况

运行公共接口例子：

```text
python -m examples.beta_window_rows
python -m examples.beta_window_rows --retime
```

`acquire()` 使用 seed=42，显式装源，初始空箔、100 µm/片、探测输出开启。两窗同轮从 0 s 开始，定时累计曝光目标各为 5 s，A 统计窗 1 s、B 统计窗 5 s。2.5 s 时改为 4 片，门不停。5 s 后分别主动保存，再关闭输出。

```python
s.configure_acquisition('counter', duration_s=5, window_s=1)
s.configure_acquisition('counter_b', duration_s=5, window_s=5)
s.start_group(('counter', 'counter_b'))
s.advance(2.5)
s.set('foil_count', 4)
s.advance(2.5)
s.snapshot('counter')
s.snapshot('counter_b')
```

| 目标 | 窗号 | 开门累计曝光 / s | 本窗实际曝光 / s | 工况 |
|---|---:|---|---:|---|
| A | 1 | 0–1 | 1 | 空箔 |
| A | 2 | 1–2 | 1 | 空箔 |
| A | 3 | 2–3 | 1 | 2–2.5 s 空箔；2.5–3 s 4片，各0.5 s |
| A | 4 | 3–4 | 1 | 4片 |
| A | 5 | 4–5 | 1 | 4片 |
| B | 1 | 0–5 | 5 | 跨工况，保留全部 parts |

计数以当前模型本次实跑及导出文件为准，不沿用旧抽样方式的固定数值。尤其不能把 A 第三窗或 B 第一窗整体标为新箔厚。

`--retime` 在 2.5 s 同时请求 A 统计窗长改为 2 s。A 第三窗仍在累计曝光 3 s 结清，下一窗覆盖 3–5 s，实际曝光为 2 s；B 仍是一窗 5 s。分别读取本次实得计数，不要求两组相加一致。新值何时生效以 `next_window_s` 和真实窗边界为准，不能立即截断当前窗。未测与有有效曝光的零计数分别表示。

`pause_resume()` 例在 3 s 用一次整机暂停，探测器保持开启、物理时间再经过 7 s，随后一次共同继续并采 2 s。两窗均保留原轮次，实际曝光分别为 5 s，墙钟首尾跨度为 12 s；3 s 保存的快照保持原值。底层专用测试另核单门暂停不影响另一门，但这不是当前学生面板的启停入口。

## 逐窗、快照与文件核对

`Session.instrument_windows(device)` 返回不可变 `InstrumentWindow`。关键字段为 `device`、`number`、`acquisition`、`start_exposure_s`、`end_exposure_s`、`counts`、`parts`、`complete`、`window_s`。`window_s` 为这次测量采用的统计窗预设，旧记录无法确认时可为空；本窗实际曝光是两个曝光边界之差，不是首尾墙钟之差或当前预设。`parts` 各有物理时刻、工况、稀疏设备读数，保留跨设置变更；不能先按工况合并后再推导逐窗值。

`complete=True` 表示窗已结清；若存在可读的未完整窗，保留其实际曝光及未完整标记。大数字显示最近完整窗时，不可用当前累计计数冒充该窗。`Snapshot.windows` 复制按键时可读的逐窗数据，后续采集不改写旧快照。只有主动保存的快照写入原始数据文件；未保存的轮次只保留元数据。

文件例子：

```text
python -m examples.beta_window_rows --directory beta-output
```

例子保存 `beta-windows.nuclemu`，分别导出 A/B 的 JSON、CSV 并读回核对原测量文档，同时输出便于跨入口比较的 `window-rows.json`。整场文件与单项都必须保留 A 五行、B 一行、每行截止曝光和 parts；缺逐窗字段应明确失败，不能只拿累计总数相同声称通过。离线重开仪器待机，浏览历史记录不抽样；从已保存记录继续计数须显式载入整机测量，不能自动恢复未保存部分。

GUI/CLI 联调必须使用相同种子、设置、窗配置和生效时刻。以下 CLI 调用用于与上述 Python 的两份测量文档逐项对照，应保留 A 五行、B 一行及各窗 parts；当前模型计数须按同一时间线实跑核对：

```text
python -m nuclemu run beta --seed 42 --set source_present=1 --set foil_count=0 --set foil_spec_um=100 --enable-output beta_detector --window counter=1 --window counter_b=5 --change 2.5,foil_count=4 --duration 5 --package beta-cli.nuclemu
```

CLI 的 `--step` 仍表示独立测点，不能拿两个 step 代替一轮热调；`--change` 的时刻相对于本轮开始。单项逐窗文件从包中选择 UUID 后用 `files export` 取得，具体调用见[命令行](cli.md)。GUI 新建默认种子为 0，与 seed=42 的固定示例不同；应按实际种子另跑同一时间线再比对，不能把不同种子的读数差异误报为入口不一致。

## 本底与专项验证

β 学生工作台只测量、保存和导出。学生在本地按各自实际曝光计算 `Ns/ts−Nb/tb` 与独立泊松近似标准不确定度；保留负净率和合法零计数。`examples.beta_background` 提供独立测量与重叠累计快照的技术对照，调用的是公共结果函数，不要求学生页面提供分析区。CLI 显式指定本底时必须随整包保留稳定记录身份及实际曝光，不能只打印结果。

```text
python -m unittest discover -s tests -p "test_beta*.py" -v
```

专项覆盖有效曲线均值/方差、片规格与面密度、空源与关电输出、单装置两窗绑定、虚拟重复观测的均值与独立抽样、五短一长逐窗/跨工况、运行改窗长、显示读取不改变计数、旧记录不重算及零计数/负净率。已知共享输入错开门、A停B继续属于公共框架底层门能力的专用验证，不是本课学生逐窗启停步骤。公共内核和文件边界另由框架及CLI验证；桌面新面板由GUI完成后以同一份数据交叉走查。
