# Nuclemu 本地实验台

Nuclemu — A Virtual Nuclear Physics Lab 使用 Python 标准库 tkinter，图谱由 Canvas 绘制，无需绘图库。可从 Python 启动：

```python
from nuclemu.gui import launch
launch()
# 附加可信的实验模块目录：launch(paths=("my_experiments",))
```

实验下拉框可在 α 能量损失和 β 吸收实验间切换。装置参数由实验声明自动生成，输入后点击“应用参数”；开始采集也会应用当前表单。参数范围和整数要求由实验定义检查，整张表单通过检查后才改变工况。采集中改变参数会结清旧工况的曝光，并开启新工况段。

“手动”采集由停止按钮结清；“定时”按输入的仿真秒数自动关门。速度改变仿真时间与实际时间之比，通过选择预设值或输入后按回车提交。暂停独立于速度编辑，冻结仿真时钟和曝光，恢复后不补计暂停期间的时间。暂停时仍可停止采集、导出或更改参数。读数只包含已经完成的曝光窗；停止会结清最后不足一秒的曝光。刷新、图谱绘制、ROI 计算和导出不产生新的随机读数。当前只支持手动和定时采集。

设备列表同时显示名称、kind 和实例 id；同型两台设备也可分别选择、查看和导出。历史段按采集门与工况分段，即使同一工况连续开门两次也分别记录。点击历史段查看旧读数，“跟随最新段”恢复当前读数。切换实验先关闭采集门，并直接保留未导出读数；同一个窗口中的各实验独立保留读数、设备和刻度，切回即可继续。关闭窗口前会提示采集中、未导出读数或未保存刻度的实验。取消关闭保留采集门与原定时终点；确认关闭才停止并丢弃未保存内容。数据只保留在内存中，关闭后需要通过已导出的文件保留记录。

应用内确认、错误提示和文件选择弹窗期间，仿真时间统一冻结；即使弹窗触发 Tk 内部刷新也不推进曝光。退出弹窗后恢复原先运行或暂停状态，不补计等待时间。显示“暂停”复选框仍表示用户自己的暂停选择，关闭确认中另有冻结说明。

谱实验可输入包含两端的 ROI 道号，点击“计算峰心”后应用并计算计数加权峰心；输入未提交或非法时，已有 ROI 和采集时钟不变。空 ROI 显示“无计数”。两点刻度使用递增道号和递增 MeV 能量，点击应用后坐标轴和峰心能量随刻度更新。“MeV 横轴”复选框可切回道号轴，刻度仍保留。保存和载入使用刻度 JSON，载入时核对实验、设备实例和道数。刻度不修改原道谱。宽 ROI 跨过多个峰时，所得为整个 ROI 的加权中心。

计数实验以读数表并列显示当前设备各历史段的工况、计数、曝光和计数率，可滚动查看或点击选段。计数率按各段自己的曝光归一，适合比较不同曝光的结果。在“扣本底”下拉框中明确选择本底历史段。软件按样品和本底各自的曝光计算净计数率及独立泊松计数的标准不确定度，允许负净率。请使用同一几何及适用条件下的独立本底段；软件不会自动判断某段是否为物理上合适的本底。查看本底段自身时只显示原始读数，不将同一份数据当成独立样品扣除。

导出按钮分别导出当前设备的所选段或全部段，支持 JSON 和 CSV。两种格式均保留曝光起止、采集序号、工况和原始计数；JSON 另保存 seed，CSV 为逐道测量行，不含 seed。有刻度时 JSON 附带刻度、CSV 附带逐道能量。扣本底是读数分析，导出保留原始样品和本底，便于重新计算。多设备实验需逐设备导出。导出后仍在增长的段会再次标记为未导出。

新应用的刻度独立跟踪保存状态；导出过旧谱不代表之后建立的刻度已保存。使用“保存刻度”或导出含该刻度的测量 JSON 可保存其定义；CSV 只存逐道能量，不解除未保存刻度提醒。从刻度 JSON 载入的当前定义视为已有文件，随后修改仍需再保存。

`Workbench` 提供无显示环境下的相同操作路径。运行 `python -m unittest discover -s tests -p "test_gui*.py" -v` 验证参考采集、设备绑定、刻度和导出；存在 Tk 显示环境时也创建真实窗口并操作控件，无显示时仅窗口测试跳过。GUI 默认 seed=0；确定性核对可用 `Workbench(seed=42)` 或 `Workbench(seed=187)` 注入 `TkWorkbench(root, controller)`。正常运行由 `launch()` 进入 Tk 事件循环。
