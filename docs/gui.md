# 本地浏览器实验台

本文以桌面浏览器中的 α、β 实验为例，说明如何操作仪器、保存读数和重开实验。

在仓库目录运行 `python -m nuclemu gui`。命令启动本机 Python 服务，并在浏览器打开实验目录。保持终端打开，结束时按 Ctrl+C 停止服务。已安装的包也可用 `nuclemu gui` 启动。课程作者可用 `python -m nuclemu gui --path D:\MyLabs` 加载自己的可信实验模块。

Python 调用保留 `from nuclemu.gui import launch`，使用 `launch(paths=("课程目录",))` 启动同一个 Web 工作台。

## 从装置到仪器

在目录中查看实验资料，或进入一场新实验。装置页列出部件、粒子路径和信号连接。选择部件可查看它的用途，调整它绑定的参数，或进入相应仪器。外部模块也使用同一份参数与设备声明，接入例子见[框架与接口](architecture.md)。

“应用参数”只提交在当前部件上改过的字段。例如，一个页面正在编辑增益，另一页已将阈值改为 3，应用增益后阈值仍为 3。若两页编辑同一字段，以最后一次成功应用的值为准。

从装置页开启探测器输出，再打开读出仪器。默认使用普通采集，按“暂停采集”读数，继续采集时沿用本轮累计值。需要另起一轮时按“清空”，有读数时可以先保存、直接清空或取消。β 的两个计数器分别控制，切换页面时正在采集的仪器会继续工作。

要限制曝光或计数，在仪器面板选“定时”或“定计数”并设置目标。定计数在完整统计窗结束时判断，读数可能超过目标，分析时使用仪器给出的实际计数和曝光。顶栏“仿真”可调倍速以缩短等候时间。

## 谱与计数

- **α 多道谱仪。** 先采无箔参考谱并保存。在图上拖选一个孤立峰，或在“分析”中输入起止道号，就能查看选区计数和计数加权峰心。用两个参考峰建立能量刻度，用第三个峰核对，再按“保存刻度”。增加箔厚后另起一轮采谱，从“显示”选择原参考谱叠加比较。曝光不同时可按曝光归一。需要逐道复算时，从实验记录下载已保存的完整道谱。[α 实验](alpha.md)
- **β 计数器。** 在装置页取下源，开启探测器输出。探测器右侧上下排列两台计数器，A 在上、B 在下，共用同一路输出。选中一台，再从详情打开对应仪器。采集并保存本底后，清空该计数器，在源座装回源，设置箔片并测量样品。在实验分析区选择本底记录，按两次测量各自的实际曝光计算净率和标准不确定度。[β 实验](beta.md)

## 保存与退出

仪器上的“保存”把当时可读的计数或道谱复制到本场缓存。正在采集时也可以保存。比如在 3 s 和 5 s 各保存一次，会得到两份有各自曝光的累计记录。它们包含重叠计数，分析时不能当作两次独立曝光。

只需测量文件时，在“实验记录”勾选要带走的记录并选择格式。计数和道谱可选 CSV 或 JSON，刻度可单独下载为 JSON。选择多项会下载一个 ZIP。

要在另一台电脑继续实验，先在仪器上保存所需读数，再在“实验记录”选择“下载整场实验”。`.nuclemu` 文件包含已保存的测量和刻度、装置末态、轮次和设置变更。未点保存的轮次保留测量条件与曝光，原始计数或道谱只保留到主动保存的那次读数。

确认浏览器已下载文件后再退出或关闭本机服务。下次在实验目录选择“打开实验文件”，可以查看当时保存的谱、计数及分析引用。重开后探测器输出和采集门均关闭，当前曝光为零。重新开启输出并采集会开始新一轮。[采集、缓存与文件](measurement-workflow.md)

## 修改界面

Vue 3 和 TypeScript 源码位于 `frontend/src/`。修改后在 `frontend/` 下使用 Node.js 20.19+（20.x）或 22.12+ 运行 `npm ci` 和 `npm run build`。构建会先检查类型，再把可离线使用的界面写入 `nuclemu/static/`。开发时将修改后的源码和对应的构建产物一起提交。装置图、谱图和样式由同目录的 `draw.js` 和 `style.css` 提供。学生机直接用 Python 启动，运行时从本机读取这些资源。
