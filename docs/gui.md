# 本地浏览器实验台

在仓库目录运行 `python -m nuclemu gui`，本机服务会打开浏览器实验目录。保持终端打开，结束时按 Ctrl+C 停止服务。已安装的包也可用 `nuclemu gui`。课程作者可用 `python -m nuclemu gui --path D:\MyLabs` 加载可信课程模块；Python入口为 `from nuclemu.gui import launch`、`launch(paths=("课程目录",))`。

## 选择课程与装置

先在目录读简介、查看资料或进入新实验。新实验为空源座，源与薄箔分别装入。实验左栏依次进入装置、绑定仪器、实验记录和实验资料。右栏“操作面板”直接调整本课开放参数；“装置介绍”用于阅读所选器材用途。选择探测器仍停留装置页；选择读出仪器后可按“打开仪器”。整机说明从右上“装置与接线”查看。

探测输出控制送到仪器的信号，仪器开始/暂停控制自己的采集门。输出关闭但门开时仍累计实际曝光；β空源而输出开启可测环境本底。顶栏“仿真”设置倍率，倍率为每现实秒推进的仿真秒数，分析使用实际曝光。

装置动画只表示当前器材状态，展示散开的源束与空气中的少量背景点，与真实计数完全无关。它不提供单粒子轨迹、散射角或定量强度，动画开关不改变测量读数。实际计数和曝光以仪器为准。

## 采集与查看资料

仪器默认普通采集，空数据按“开始”，已有曝光按“继续”，暂停后读数保留。定时和定计数在当前仪器面板设置目标，针对本轮累计曝光或计数。定计数在完整统计窗末判断，可能超过目标；使用实际值分析。暂停、到限不自动保存。

α右栏“采集”和“谱分析”切换实际工具，状态和暂停入口保持可达。“谱分析”选择当前、已保存与参考谱，设置ROI并读区内计数、加权峰心和适用刻度能量。两点刻度先应用，再手动保存；空ROI没有可测峰心。绘图区自动适配，完整道数据仍可下载。[α学生章](alpha.md)

β为一台计数器内的两窗，A左、B右，代表同一工况下分别取样的两组虚拟重复观测。每窗大计数下方设置单次曝光，下方列表逐行显示实际曝光和整数计数。整机一组“开始测量／继续测量”“暂停测量”同时控制两窗；右栏设置共同采集模式及目标，“保存、清空与载入目标”只决定这些操作作用哪一窗，切换选择不启停采集。开始或继续时，两窗从各自已有读数累计，各列单次曝光分别保留。工作台保存原始读数，学生下载后自行处理本底。[β学生章](beta.md)

从左栏“实验资料”阅读与独立手册相同的正文。采集中阅读不会主动暂停仪器；返回后核对新读数和当前操作对象。

## 保存、清空和载入测量

“保存”复制按键时可读的快照到本场实验记录，后续续采不改旧值。3s和5s各保存一次是两份重叠累计快照，不能当独立曝光相加。

清空未保存数据提供“保存并清空”“直接清空”“取消”；只清空目标仪器或窗，保留其窗长和预设。零计数但已有曝光也属于测量数据。

仪器“载入测量数据”可从本场记录或源文件取数。非空目标先提示“载入将覆盖当前测量数据”；取消或文件无效时保留原值。载入后按“继续”从已有值累计，β追加新窗，原缓存和源文件不改写。参考谱叠加、载入刻度与载入测量是不同操作。

## 下载与重开

“实验记录”的“导入记录”只增加缓存，不改变当前仪器。每条按类型、设备/窗、工况和实际曝光辨认；勾选后“导出所选”，单项可选CSV或JSON，刻度为JSON，多项下载为ZIP。

“下载整场实验”或“文件 → 保存实验”下载 `.nuclemu`，包含全部已留存记录、装置末态、轮次与设置变更。勾选只影响单项导出。3s留存后续采到5s，整场可有5s轮次元数据和3s原始快照；未保存的一轮没有已存读数，不能伪造为零。

默认下载名带实验短码和现实保存时间，便于辨认同一课程的多次文件；α能损用 `AEL`，β吸收用 `BABS`。这里的时间是现实保存时刻，测量曝光仍以文件中的实际曝光为准。整场文件以 `.nuclemu` 识别；所选记录按下载内容使用 `.csv`、`.json`，多项为 `.zip`。导入依据文件内容校验，无须按指定名称重命名后才能载入。

文件菜单依次为“载入实验”“保存实验”“退出实验”。确认文件下载后再退出；取消文件选择可继续当前实验。载入已有实验后仪器待机，可浏览已保存记录；需要从保存值续采时，在仪器显式载入相应测量数据。[采集与文件语义](measurement-workflow.md)

## 界面维护

Vue 3/TypeScript源码位于 `frontend/src/`。修改后在 `frontend/` 使用支持的Node.js版本运行 `npm ci`、`npm run build`，构建会检查类型并写入可离线资源 `nuclemu/static/`；源码和构建产物一起交付。学生机运行时从本机读取资源。学生正文为 `docs/alpha.md`、`docs/beta.md`，由 `frontend/src/studentMaterials.ts` 导入，目录简介读取首节“实验简介与目的”。修改正文后也需重新构建。
