# 本地浏览器实验台

在仓库目录运行 `python -m nuclemu gui`，本机服务会打开浏览器实验目录。保持终端打开，结束时按 Ctrl+C 停止服务。已安装的包也可用 `nuclemu gui`。

## 选择课程与装置

先在目录读简介，再按卡底“进入实验”开始新实验；完整教材从实验内左栏“实验资料”阅读。新实验为空源座，源与薄箔分别装入。实验左栏依次进入装置、绑定仪器、实验记录和实验资料。右栏“操作面板”直接调整本课开放参数；“装置介绍”用于阅读所选器材用途。选择探测器仍停留装置页；选择读出仪器后可按“打开仪器”。整机说明从右上“装置与接线”查看。

探测输出控制送到仪器的信号，仪器开始/暂停控制自己的采集门。输出关闭但门开时仍累计实际曝光；β空源而输出开启可测环境本底。顶栏“仿真”设置倍率，倍率为每现实秒推进的仿真秒数，分析使用实际曝光。

装置动画只表示当前器材状态，展示散开的源束与空气中的少量背景点，与真实计数完全无关。它不提供单粒子轨迹、散射角或定量强度，动画开关不改变测量读数。实际计数和曝光以仪器为准。

## 采集与查看资料

仪器默认普通采集，空数据按“开始”，已有曝光按“继续”，暂停后读数保留。定时和定计数在当前仪器面板设置目标，针对本轮累计曝光或计数。定计数在完整统计窗末判断，可能超过目标；使用实际值分析。暂停、到限不自动保存。

α右栏“采集”和“谱分析”切换实际工具，状态和暂停入口保持可达。“谱分析”选择当前、已保存与参考谱，设置ROI后按“计算 ROI 重心”，读取本次区内计数、重心、截止曝光和适用刻度能量。结果保持本次所选谱、道界与刻度，续采或修改输入后须主动重算。计算不自动保存原谱；结果属于当前会话，重开文件后要从已保存谱重新计算。两点刻度先应用，再手动保存；空ROI没有可测峰心。横轴固定全道0–1023，切到能量轴只换算全道两端，完整道数据仍可下载。[α学生章](alpha.md)

β为一台计数器内的两窗，A左、B右，代表同一工况下分别取样的两组虚拟重复观测。每窗大计数下方设置单次曝光，下方列表逐行显示实际曝光和整数计数。整机一组“开始测量／继续测量”“暂停测量”同时控制两窗；右栏设置共同采集模式及目标，保存、清空和载入均一次作用于整台计数器，两窗读数一起处理。开始或继续时，两窗从各自已有读数累计，各列单次曝光分别保留。工作台保存原始读数，学生下载后自行处理本底。[β学生章](beta.md)

从左栏“实验资料”阅读与独立手册相同的正文。采集中阅读不会主动暂停仪器；返回后核对新读数和当前操作对象。

## 保存、清空和载入测量

“保存”打开命名窗口，预填实验缩写与时间，可接受、修改或取消。确认后把按键时可读的测量保留到本场实验记录；β一次保留A/B，允许两侧行数不同；表中可读的部分曝光保留实际计数和曝光，不补成完整窗。0 s无读数的一侧不造记录，大读数无完整窗时显示“—”。记录页可再改名，同名记录按稳定身份区分，名称改变不改刻度或来源关联。后续续采不改旧值。3s和5s各保存一次是两份重叠累计快照，不能当独立曝光相加。

清空未保存数据提供“保存并清空”“直接清空”“取消”；清空当前仪器；β同时处理A/B，保留各窗窗长和预设。零计数但已有曝光也属于测量数据。

仪器“载入测量数据”可从本场记录或源文件取数。非空目标先提示“载入将覆盖当前测量数据”；β一次确认并整体恢复A/B。取消或文件无效时保留原值。载入后按“继续”从已有值累计，β追加新窗，原缓存和源文件不改写。历史单窗文件按文件内设备自动载入对应窗，另一窗保持原值；新版整机文件恢复整机，缺测侧留空，无选窗或配对控件。参考谱叠加、载入刻度与载入测量是不同操作。

## 下载与重开

“实验记录”的“导入记录”只增加缓存，不改变当前仪器。每条按类型、仪器和实际曝光辨认，必要的工况信息可展开核对；勾选后“导出所选”，单项可选CSV或JSON，刻度为JSON，多项下载为ZIP。

“下载整场实验”或“文件 → 保存实验”下载 `.nuclemu`，包含全部已留存记录、装置末态、轮次与设置变更。勾选只影响单项导出。3s留存后续采到5s，整场可有5s轮次元数据和3s原始快照；未保存的一轮没有已存读数，不能伪造为零。

默认下载名带实验短码和现实保存时间，便于辨认同一课程的多次文件；α能损用 `AEL`，β吸收用 `BABS`。这里的时间是现实保存时刻，测量曝光仍以文件中的实际曝光为准。整场文件以 `.nuclemu` 识别；所选记录按下载内容使用 `.csv`、`.json`，多项为 `.zip`。导入依据文件内容校验，无须按指定名称重命名后才能载入。

文件菜单依次为“载入实验”“保存实验”“退出实验”。退出时询问“退出前是否保存实验？”，可选“保存”“放弃”“取消”。尚未下载的本场记录也会随离场丢失；取消返回原页面与读数。能获知写入失败或用户取消保存时，保留当前实验；发起下载后仅显示“取消”和“确认退出”；取消返回实验，确认文件到手后再按“确认退出”。取消载入文件选择也可继续当前实验。例如3 s保存后又测到5 s但未保存，重开只保留3 s测量和该轮曾到5 s的元数据；仪器门关闭、当前曝光从0 s开始，不恢复未保存的5 s计数，也不自动将3 s记录载入当前仪器。载入已有实验后仪器待机，可浏览已保存记录；需要从保存值续采时，在仪器显式载入相应测量数据。
