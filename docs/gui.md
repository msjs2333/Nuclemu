# 本地浏览器实验台

本文说明当前发布版的操作。下一轮的会话缓存、批量下载及实验文件设计见[采集、缓存与文件](measurement-workflow.md)。

在仓库目录运行 `python -m nuclemu gui`。命令启动本机 Python 服务，并在浏览器打开实验目录。保持终端打开，结束时按 Ctrl+C 停止服务。已安装的包也可用 `nuclemu gui` 启动。课程作者可用 `python -m nuclemu gui --path D:\MyLabs` 加载自己的可信实验模块。

Python 调用保留 `from nuclemu.gui import launch`，使用 `launch(paths=("课程目录",))` 启动同一个 Web 工作台。

## 从装置到仪器

在目录中查看实验资料，或进入一场新实验。装置页列出部件、粒子路径和信号连接。选择部件可查看它的用途，调整它绑定的参数，或进入相应仪器。外部模块也使用同一份参数与设备声明，接入例子见[框架与接口](architecture.md)。

“应用参数”只提交在当前部件上改过的字段。例如，一个页面正在编辑增益，另一页已将阈值改为 3，应用增益后阈值仍为 3。若两页编辑同一字段，以最后一次成功应用的值为准。

在顶栏“采集”中选择手动或定时、输入曝光秒数，再用仪器页的采集按钮开门。全局暂停会冻结仿真时间，改变倍速会改变等待时间。“停止采集”会结清页面所示这次采集的实际曝光，包括最后不足一秒的部分。若另一页已开启下一次采集，工作台会提示重新查看。切换装置、仪器和记录页可以继续采集。采集中改变工况会把前后曝光分别记录；同一工况连续开两次门，也会得到两次独立测量。

## 谱与计数

- **α 多道谱仪。** 先采无箔参考谱，在图上或用起止道号选定一个孤立峰的 ROI，计算计数加权峰心。在“分析”中用两个参考峰的道号与已知能量建立刻度，再用第三个峰核对。增加箔厚后重新采谱，从“显示”选择原参考谱叠加比较；曝光不同时可以按曝光归一。空选区没有可测峰心。道号与能量横轴共用原始道谱。[α 实验](alpha.md)
- **β 计数器。** 从源座的“在计数器选择测量模式”进入计数器，在表格上方选择“本底”并采集，再选“有源”测样品；箔片数仍在装置页调整。模式切换不会自动开门。计数表直接列出各段工况、实际曝光、整数计数和计数率，表上方唯一的“本底记录”可选不同本底，样品行显示净率 ± 标准不确定度。本底行标为参考，零计数和负净率正常保留。本底与样品允许使用不同曝光。窄屏在表内横向滚动；只读存档可切换本底分析但不能改变工况或开门。源模式没有明确唯一绑定的外部课程保留装置页通用控件，两台计数器分别保留各自的参考选择。[β 实验](beta.md)

## 保存与退出

在实验记录页选择设备、测量段及各自的格式。道谱和计数可用 CSV 或 JSON，刻度可以单独导出为 JSON。选择多项会下载一个 ZIP，各文件取自同一仿真时刻。浏览器接手下载后，实验台仍保留未保存提醒。要保留整场实验及分析选择，使用顶栏“文件”中的“保存整场实验”。下次从目录打开存档，可以重新查看道谱、刻度和扣本底所用的参考记录。

同一本机服务中的浏览器页签共享正在运行的一场实验。服务运行时刷新页面会重新连接原会话。重启服务后，可以从目录打开最近的草稿，查看截至上次已记录曝光的读数。存档和草稿默认位于用户目录下的 `.nuclemu/workbench/workbench.sqlite3`。

从目录打开存档或草稿后，可以重新选择谱峰、本底或刻度，再把测量记录和本次分析另存为副本。同一个查看窗口再次保存会更新这份副本。原存档仍保留原来的分析；如果另一工作台正在采集，它仍可用自己的草稿恢复到最近一次已记录的曝光。关闭查看窗口时放弃的只是本次未保存的修改。

采集中点击“保存整场实验”会保存已经完成的曝光窗。记录的截止时刻可以早于屏幕上的实验室时钟；仪器继续累计原来的测量。“退出实验”或浏览器后退会打开退出确认。选择“继续实验”可回到当前仪器；确认期间不计入曝光。“保存实验并退出”还会结清当时不足一窗的曝光，写入成功后返回目录。写入失败时可以重试或继续，定时门保留原终点。

## 修改界面

Vue 3 和 TypeScript 源码位于 `frontend/src/`。修改后在 `frontend/` 下使用 Node.js 20.19+（20.x）或 22.12+ 运行 `npm ci` 和 `npm run build`。构建会先检查类型，再把可离线使用的界面写入 `nuclemu/static/`。开发时将修改后的源码和对应的构建产物一起提交。装置图、谱图和样式由同目录的 `draw.js` 和 `style.css` 提供。学生机直接用 Python 启动，运行时从本机读取这些资源。
