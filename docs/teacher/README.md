# 教师教学用书

Nuclemu · **A Virtual Nuclear Physics Lab**

本册面向备课和课堂指导，配合[学生实验手册](../student.md)使用。技术常数和接口由[技术参考](../technical/README.md)维护；教师可以讨论典型结果，但不把它们作为学生应复现的指定随机数。

## 目录与备课路径

1. [α 能量损失](alpha.md)：先核空源和空箔，再采参考谱、两点刻度、第三峰检查、加箔跟峰与射程解释。
2. [β 吸收](beta.md)：先认识双窗及曝光，再独立测本底和样品，比较按曝光归一后的净率。

## 共用课堂安排

课前打开一场新实验，核对默认空源、材料规格和仪器入口。试走一次“采集 → 保存 → 下载 → 载入实验”，确认学生文件能读到空表所需字段。按课时决定测点数和曝光，厚箔或低计数处允许延长测时。

先让学生解释读数来自哪个窗或哪张谱，再讨论物理。特别区分：尚未测量；实际曝光后零计数；轮次存在但无已存读数；同轮不同截止点的累计快照。同轮不同截止点的累计快照可能共享计数，不能当独立重复测量。

收表时抽查一行，从学生自己的文件核对工况、实际曝光、整数计数或完整道谱、刻度和本底依据。评价单位、分析与可追溯性；单次统计涨落不应按固定答案评分。
