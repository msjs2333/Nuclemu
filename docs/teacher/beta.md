# β 射线吸收 · 教师用书

本章用于备课、课堂观察与收表。[学生章及空表](../beta.md) · [技术参考](../technical/beta.md) · [本册目录](README.md)

## 备课与建议测点

先让学生认识一台计数器内的 A、B 两窗，整机同步启停，可固定用A记录处理吸收曲线。先安排 A=1 s、B=5 s，观察逐窗读数与整机暂停、续采；测曲线则取空源60 s本底、有源0/4/8/16片各20 s，单片100 µm。厚箔处按实得计数延长曝光，不要求所有测点同测时。

新课为空源，需学生主动装源。空箔架不等于空源；关闭探测输出也不能代替空源本底。保持固定几何与探测条件，先保存前一点，再清空并采下一点。运行中换箔可用于观察跨工况窗，但这种窗不能当作单一厚度测点。

装置动画只表当前器材状态，散开的源束和少量背景点与实际计数无关。不能通过点数、疏密或运动轨迹推断净率。背景点只是视觉元素，课堂本底仍需空源、探测输出开启后用计数器测得。

| 教学检查点 | 观察与追问 |
|---|---|
| 空源、输出开启 | 环境本底仍可计数；短窗零次是合法读数。 |
| 整机暂停或继续 | 两窗同时响应，保留各自曝光和读数，不要求学生逐个开门或管理全局时钟。 |
| 窗长和曝光 | 大数字属于最近结清窗；手停不足整窗时按实际曝光记录。 |
| 长短窗比较 | 两路关系由输入和门区间决定，不能仅因同工况要求相等或严格相加。 |
| 保存后续采 | 旧快照保持截止值，累计新值不能回填旧记录。 |
| 下载与重开 | 只读已保存原始值；无已存读数不能填零。 |

## 如何讨论双窗

本课A左B右，每窗大计数下方设置单次曝光；右栏共同模式和目标用于整机“开始测量／继续测量”“暂停测量”，保存、清空、载入另选目标窗。单次曝光决定本窗出数间隔，定时目标限制累计曝光，不应混填。这是教学显示与操作约定。实物资料可支持双路独立门控或逐次留读，不能据此声称某型号具备本课所有显示与预设功能。[ORTEC 995](https://www.ortec-online.com/-/media/ametekortec/brochures/9/995-a4.pdf) · [Spectrum Techniques ST260](https://www.spectrumtechniques.com/wp-content/uploads/ST260-Manual.pdf)

安排同步的1 s/5 s窗时，按整机开始，分别检查A五行、B一行及其实际曝光。暂停同时作用两窗；保存或清空只作用当前所选窗。已知脉冲输入可用于技术验证底层门边界；不要把该专用条件下的相加关系作为学生随机计数实验的普遍结论。底层独立门能力不等于学生端逐个开门，也不意味着随机计数必须独立。

在2.5 s换箔的受控示例中，A第3窗与B第1窗应包含前后条件；两窗按原节奏继续。运行改A窗长，本窗按原长收完，下窗用新长，B不变。观察列表与导出文件中的分段条件，避免把整窗标作新箔厚。

## 本底与数据处理

学生在本地按实际曝光计算 `r = Ns/ts − Nb/tb`，独立泊松近似标准不确定度 `u = sqrt(Ns/ts² + Nb/tb²)`。不在工作台预先替学生选本底、扣除或显示净率。收表时核对空源本底的设备、探测设置、记录身份和曝光，不能只看计数率像不像本底。

低计数下负净率保留；零计数项代入为零不代表真实方差为零。“净率 ± u”不是低计数精确置信区间。若延长测时，应另行保留原始计数与实际曝光，不能将不喜欢的读数删去。

多个样品共用一份独立本底时，两净率协方差的代入估计为 `Nb/tb²`。同轮3 s和5 s累计快照共享前3 s，不能视为独立样品。同输入重叠窗也可能相关；一般有 `Var(r1−r2)=Var(r1)+Var(r2)−2Cov(r1,r2)`，不能仅凭两份整数读数确定相关项。

## 教师预期与模型边界

以下为模型均值，供选择测时，不是学生应抄出的测量值。当前固定几何下，无附加箔净率100 s⁻¹，本底2 s⁻¹，100 µm Al每片面密度0.027 g/cm²；有效半值面密度0.112 g/cm²。

| 片数 | 期望总率 / s⁻¹ | 20 s期望计数 |
|---:|---:|---:|
| 0 | 102.0000 | 2040.00 |
| 4 | 53.2532 | 1065.06 |
| 8 | 28.2689 | 565.38 |
| 16 | 8.9006 | 178.01 |

60 s空源本底的期望计数120，实得整数会涨落。该有效吸收式适用于课程固定条件，不是完整β连续谱输运，不能把拟合半值厚度解释为最大射程。关于文献中剂量衰减尺度与本课计数响应的区别见[模型参考](../model-reference.md#beta)。

## 用学生文件验收

可用下列实际采集检查空表的计数率处理：种子42，两窗同时开始；空源、空箔60 s后保存A并清空两窗，再装源、100 µm/片×4片两窗同时测20 s，保存A。均保留默认1 s窗，A分别有60行与20行。这里只用A的记录计算净率。

| 记录 | 源状态 | 实际曝光 / s | 原始计数 | 总率 / s⁻¹ |
|---|---|---:|---:|---:|
| 本底 | 空 | 60 | 110 | 1.833333 |
| 样品 | 有源、4片 | 20 | 1065 | 53.250000 |

样品总厚400 µm，面密度0.108 g/cm²；按两份独立测量得到净率51.416667 s⁻¹、近似标准不确定度1.641053 s⁻¹。JSON、CSV与整场文件读回的整数和曝光相同。复验操作见[技术册调用](../technical/beta.md#一行填写示例的复验)。这些数字属于这条时间线，不是学生曲线的指定答案。

让学生从下载文件填写一行独立本底、一行无箔和至少一个加箔测点，逐项核对原始整数计数、实际曝光、源状态、材料、片数、窗号及本底身份。对同一份样品换两份独立本底，只改变分析结果，样品原始数不变。

若用多行合并，检查这些窗不重叠且工况一致；若用累计快照，只取适用的一份，不能重复相加。把未测、已测零次、该轮无留存和重叠快照四种情形分别提问。评价曝光归一、统计解释与可追溯性，不按指定种子的固定整数评分。

最终课堂验收以当前工作台实际导出并重开的文件为依据。课程样例与字段复验入口见[β器材与采集](../beta-acquisition.md)，脚本通过不代替页面走读。
