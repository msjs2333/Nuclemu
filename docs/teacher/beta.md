# β 射线吸收 · 教师用书

本章用于备课、课堂观察与收表。[学生章及空表](../beta.md) · [技术参考](../technical/beta.md) · [本册目录](README.md)

## 备课与建议测点

先让学生认识一台计数器内的 A、B 两窗，整机同步启停，可固定用A记录处理吸收曲线。先安排 A=1 s、B=5 s，观察逐窗读数与整机暂停、续采；测曲线建议取空源30 s本底，100 µm规格的0/1/2/4/8/12/14片各5 s。厚箔处按实得计数延长曝光，不要求所有测点同测时。

新课为空源，需学生主动装源。空箔架不等于空源；关闭探测输出也不能代替空源本底。保持固定几何与探测条件，先保存前一点，再清空并采下一点。运行中换箔可用于观察跨工况窗，但这种窗不能当作单一厚度测点。

装置动画只表当前器材状态，散开的源束和少量背景点与实际计数无关。不能通过点数、疏密或运动轨迹推断净率。背景点只是视觉元素，课堂本底仍需空源、探测输出开启后用计数器测得。

| 教学检查点 | 观察与追问 |
|---|---|
| 空源、输出开启 | 环境本底仍可计数；短窗零次是合法读数。 |
| 整机暂停或继续 | 两窗同时响应，保留各自曝光和读数，不要求学生逐个开门或管理全局时钟。 |
| 窗长和曝光 | 大数字属于最近完整曝光窗；手停不足整窗时按实际曝光记录。 |
| 长短窗比较 | A、B 是同工况分别取样的虚拟重复观测；五短窗之和与同期一长窗可不同，也可偶然相同。 |
| 保存后续采 | 旧快照保持截止值，累计新值不能回填旧记录。 |
| 下载与重开 | 只读已保存原始值；无已存读数不能填零。 |

## 如何讨论双窗

本课A左B右，每窗大计数下方设置单次曝光；右栏共同模式和目标用于整机“开始测量／继续测量”“暂停测量”，保存、清空和载入一次处理两窗。单次曝光决定本窗出数间隔，定时目标限制累计曝光，不应混填。本课还约定 A、B 表示同一装置条件下的两组虚拟重复观测，按同一平均响应分别取样，类似重复做两次实验；不是把同一真实脉冲重新随机计数。显示、操作及虚拟重复观测均为教学约定。实物资料可支持双路独立门控或逐次留读，不能据此推出分别抽样，或声称某型号具备本课所有显示与预设功能。[ORTEC 995](https://www.ortec-online.com/-/media/ametekortec/brochures/9/995-a4.pdf) · [Spectrum Techniques ST260](https://www.spectrumtechniques.com/wp-content/uploads/ST260-Manual.pdf)

安排同步的1 s/5 s窗时，按整机开始，分别检查A五行、B一行及其实际曝光。暂停同时作用两窗；保存或清空同时作用于两窗，无须选窗或配对。A、B 在给定工况下分别取样，比较时先按各自曝光归一，不要求计数相等、不同或严格相加。公共框架另有真实共享输入的理想无损分接：同一批计数只生成一次再分发，用已知输入核门边界；该技术验证不代表本课两组虚拟重复观测。底层独立门能力也不等于学生端逐个开门。

在2.5 s换箔的受控示例中，A第3窗与B第1窗应包含前后条件；两窗按原节奏继续。运行改A窗长，本窗按原长收完，下窗用新长，B不变。观察列表与导出文件中的分段条件，避免把整窗标作新箔厚。

## 本底与数据处理

学生在本地按实际曝光计算 `r = Ns/ts − Nb/tb`，独立泊松近似标准不确定度 `u = sqrt(Ns/ts² + Nb/tb²)`。不在工作台预先替学生选本底、扣除或显示净率。收表时核对空源本底的设备、探测设置、记录身份和曝光，不能只看计数率像不像本底。

低计数下负净率保留；零计数项代入为零不代表真实方差为零。“净率 ± u”不是低计数精确置信区间。若延长测时，应另行保留原始计数与实际曝光，不能将不喜欢的读数删去。

多个样品共用一份独立本底时，两净率协方差的代入估计为 `Nb/tb²`。本课 A、B 在给定工况下的抽样相互独立，但同一组同轮3 s和5 s累计快照共享前3 s，不能视为独立样品；载入同一旧记录产生的共同前缀也不独立。一般有 `Var(r1−r2)=Var(r1)+Var(r2)−2Cov(r1,r2)`，不能仅凭两份整数读数确定相关项。

## 教师预期与模型边界

以下为当前课程经验模型的均值，供安排曝光，不是学生应抄出的测量值。空源本底50 s⁻¹，零箔总率11650 s⁻¹。100 µm Al每片面密度0.027 g/cm²，50 µm两片与100 µm一片对应同一面密度。

| 100 µm片数 | 面密度 / g·cm⁻² | 期望总率 / s⁻¹ | 期望净率 / s⁻¹ | 5 s样品、30 s本底的净率相对u |
|---:|---:|---:|---:|---:|
| 0 | 0.000 | 11650.00 | 11600.00 | 0.42% |
| 1 | 0.027 | 4999.84 | 4949.84 | 0.64% |
| 2 | 0.054 | 2655.59 | 2605.59 | 0.89% |
| 4 | 0.108 | 1452.01 | 1402.01 | 1.22% |
| 8 | 0.216 | 1046.79 | 996.79 | 1.46% |
| 12 | 0.324 | 834.46 | 784.46 | 1.66% |
| 14 | 0.378 | 746.57 | 696.57 | 1.76% |

表中相对标准不确定度由独立泊松近似 `sqrt(R/ts + B/tb)/(R−B)`估计，`ts=5 s`、`tb=30 s`。一组观测的预计值约0.42–1.76%，仅反映计数统计，不包括模型、几何或材料误差。30 s本底加七点各5 s共65个模型秒，只是计数用时，不包括装配、讨论、保存和数据处理。可用1/5/10 s窗比较涨落，按实际读数决定是否延长。

前段快速下降与厚端缓变由双成分经验响应描述，不能把厚端仍存在的源相关计数全部当作环境本底，也不将两项对应到特定粒子物种。主要校核范围为0–0.4 g/cm²；100 µm规格15片起属于教学外推，16/20/24片分别为0.432/0.540/0.648 g/cm²。50 µm规格24片为0.324 g/cm²。允许设置不证明域外准确度；统计误差小也不保证外推可靠。详见[模型参考](../model-reference.md#beta)。

## 用学生文件验收

按以下受控时间线核对空表处理：种子42，两窗同时开始；空源、空箔30 s后整机保存并清空，再装源、100 µm/片×4片两窗同时测5 s，整机保存。均保留默认1 s窗，A分别应有30行与5行。只用A的记录计算净率；原始计数从本次导出文件读取，不沿用旧模型的固定整数。

样品总厚400 µm，面密度0.108 g/cm²。分别由文件中的 `Nb, tb` 与 `Ns, ts` 计算总率、净率与近似标准不确定度，并核对JSON、CSV和整场文件重开后的整数与曝光。复验操作见[技术册调用](../technical/beta.md#一行填写示例的复验)。固定种子用于复现操作线，不是学生曲线的指定答案。旧整场文件可能保留历史共享输入模式，课堂应核对文件模式，不把旧读数当作新课的两组独立重复观测。

让学生从下载文件填写一行独立本底、一行无箔和至少一个加箔测点，逐项核对原始整数计数、实际曝光、源状态、材料、片数、窗号及本底身份。对同一份样品换两份独立本底，只改变分析结果，样品原始数不变。

若用多行合并，检查这些窗不重叠且工况一致；若用累计快照，只取适用的一份，不能重复相加。把未测、已测零次、该轮无留存和重叠快照四种情形分别提问。评价曝光归一、统计解释与可追溯性，不按指定种子的固定整数评分。

最终课堂验收以当前工作台实际导出并重开的文件为依据。课程样例与字段复验入口见[β器材与采集](../beta-acquisition.md)，脚本通过不代替页面走读。
