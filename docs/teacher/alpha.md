# α 粒子在铝箔中的能量损失 · 教师用书

学生正文及空表见[α 能量损失](../alpha.md)，模型与复验入口见[技术参考](../technical/alpha.md)，[本册目录](README.md)提供两课备课路径。先让学生从谱形选择孤立峰，再讨论刻度和能损；不以复现指定随机整数作为评分依据。

## 备课与测点安排

新课为空源座，先让学生主动装入参考源，认识空源与空箔。建议选1 µm/片，依次测0、5、15片，各曝光60 s；30片作为可选的停止边界观察。每个单一工况测点先保存再清空，不把混合工况累计谱当作某一厚度的谱。先用外侧两峰标定，用中峰独立检查，再跟踪中峰。课时不足时可减少测点，不能用模型值填补缺测。

装置动画只提示器材状态，散开的束与背景点不代表实际输入脉冲或计数，也不是单粒子输运结果。特别说明α画面中的背景点不意味着计数模型有本底；判断是否有峰、是否停止均看保存的谱与曝光。

## 课堂检查点

| 操作或判断 | 应观察的结果 |
|---|---|
| 空源与空箔 | 空箔仍有参考源谱；本课空源无本底输入。 |
| 独立控制输出与采集门 | 门开而输出关闭时曝光仍累计、新增计数为零，已有计数保留；门关闭才停止该仪器曝光。 |
| 两点刻度与第三峰检查 | 两端点按定义落在参考能量，第三峰提供独立检查。 |
| 加箔继续使用原刻度 | 不能用参考能量重标加箔峰来消除能损。 |
| 零计数峰区 | 峰心无定义，不得记作测得 0 MeV。 |
| 保存后继续采集 | 保存谱保持原截止曝光，不使用后来的当前曝光。 |

## 统计与刻度误差

对于计数较多、孤立且 ROI 截断可忽略的峰，可估计峰心统计标准不确定度：`u_c = sqrt{Σ[n(c) × (c − 峰心)²] / [N × (N − 1)]}`。

本例无箔、5 µm、15 µm 中间峰分别得到 0.052995、0.051005、0.052406 道。暂固定斜率，只传播两份独立谱的计数统计量，5 µm 能损的标准不确定度分量约为 `b × sqrt(u_无箔² + u_加箔²) = 0.00044 MeV`。这不是完整误差预算，未包含刻度系数的不确定度与相关性、ROI 选择和模型系统误差。低计数或无峰时不机械套用。

多个样品共用无箔峰心与刻度时，能损之间相关。同轮累计快照共享早期计数，也不能当作独立重复测量。讨论拟合或差值前先辨认共享数据。

## 问题定位与收表

| 现象 | 先核对 |
|---|---|
| 谱为空 | 源座、输出、门、实际曝光和厚度；零计数本身不能区分原因。 |
| 峰区计数骤降 | 峰是否移出旧 ROI。 |
| 加箔能损接近零 | 是否错误地重标了加箔峰。 |
| 文件与表格曝光不符 | 是否给旧快照填了当前曝光。 |
| 历史档只有总厚度 | 保留厚度，未知规格和片数留空。 |

从学生带走的文件核对设备、测量身份、器材状态、原始谱、实际曝光、ROI 和刻度。逐道复算使用已保存谱导出的 CSV/JSON。缺少保存记录时标缺依据，不由模型常数补算答案。评价解释、单位和可追溯性，不按固定随机整数评分。

最终验收用桌面浏览器按学生步骤采集、保存、导出并在另一会话重开，核对谱、刻度和空表所需字段。脚本复验不代替最终页面走读。
