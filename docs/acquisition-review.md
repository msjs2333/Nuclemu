## 开工后的分工与依赖

下表列出实施分工和接口依赖。维护者用同一份样本交叉核对仪器读数、文件和界面；课程依据与教材文案可以并行准备。

| 负责人 | 交付与边界 | 交给谁核对 |
|---|---|---|
| 基础框架 | 门和统计窗、清空前后结算、保留预设、不可变快照与逐窗明细；SQLite 轮次、末态、有效设置变化、文件重开及新轮随机序列。核对旧文件可读。 | 先给 β、GUI、CLI 一组 A/B 门时间线和一份能读回的样本，约定实例/窗/轮次/记录身份。与 GUI 确认清空待决状态和导入目标。 |
| α 课程 | 空源座与材料、穿箔能损、真实可调参数、谱与刻度关联。提供有箔／无箔、跨工况及刻度不同的两谱。 | 与 GUI 对 ROI、峰心、开始和清空两条保存路径；给教材维护者核材料、单位、课堂可做操作。 |
| β 课程 | 一台双窗计数器的课程绑定、窗口输入和统计假设、热调工况、逐窗读数与旧记录映射。提供 1 s／5 s 及跨窗换箔样例。 | 框架核窗边界、GUI 核大读数及逐行显示、CLI 核导出，教材据此撰写本底和样品测量。 |
| GUI 与 Web 操作层 | 绑定仪器与常驻右栏、接线/粒子流、目录/资料/记录、稳定状态提示、清空重接、谱身份和刻度、记录导入及覆盖。负责源界面至浏览器实操链路。 | 与框架约定读取和写入何时生效，复用课程物理量。提交桌面图或操作录屏，以及切页、刷新、保存、读回得到的实际读数。 |
| CLI | 对同一课、设置、种子与时间线核对 GUI/CLI 读数，验证 JSON/CSV 和整场往返。修 CLI 已指定本底在包中的引用。 | 与框架及 GUI 交换同一份文件，核对逐窗值、刻度及曝光，和 β 复算净率。 |
| 教材与文案 | 首责是目录简介、器材科普、按钮/空状态文案、学生教材与空表、教师备课用书。整理技术参考，关键字段、计算和适用域由维护该模块的人复核。 | α、β 核物理，GUI 核实际按钮与入口，框架和 CLI 核文件示例；学生正文在内置阅读和独立版采用同一来源。 |
| 主导与交叉复核 | 处理跨模块分歧、安排按评论复现，复核 PR 上的本次修正。维护者自验之后再交叉走查。 | P1 三条都要用原操作重验；七个 issue 分别对照验收，部分拆出时调整关闭关联。 |

开工时先逐项对照[七个 issue 对应工作流](measurement-workflow.md#交付顺序与验收)、[PR 全部讨论](https://github.com/msjs2333/Nuclemu/pull/13)、正式审阅与本次工作台规范。接到跨模块工作，用一个具体操作和预期读数与对接人核实；缺字段、归属冲突或物理行为不明时，带着实例和分歧找主导裁决。交接写清对应评论、实际版本、操作、读数或画面、证据位置及仍待处理项。绿灯测试的数量不能代替按此次复现路径操作。
