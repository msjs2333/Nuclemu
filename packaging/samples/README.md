# Installation test files

These files were saved with the Nuclemu 0.0.1 Windows x64 directory build using seed 187 and a 3 s exposure. They exercise reopening an existing experiment after installing or upgrading the application.

| File | Saved instrument readings |
|---|---|
| `AEL.nuclemu` | A 1,024-channel spectrum with 221 counts. Calibration maps channels 0 and 1,000 to 0 and 6 MeV. |
| `BABS.nuclemu` | Window A recorded 11,603, 11,566 and 11,556 counts in three complete 1 s intervals. Window B recorded 34,778 counts in one partial interval of 3 s. |
